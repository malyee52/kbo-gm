# 장기 진행 개선안 (H1 입대 폭증 · H5 기량 하락 · H7 포수 부족)

작성일: 2026-10-11. 상태: **적용** (7장). 1~6장은 처음 진단과 제안이고, 사용자 결정(입대 선택 탭, 병역은 실제 자료, 3·4번은 Claude가 찾기)에 따라 고친 결과는 7장. 값은 모두 임시값.

## 1. 진단

`tools/flow_longterm.ts`로 2026년부터 15시즌을 돌렸다 (모든 구단 AI, 시드 `diag-a`·`diag-b`, 2041년 개막까지).
"기여"는 대체 선수 대비 한 시즌 런(`currentRuns`)이다. "상위 270명"은 10구단 × 27명으로, 1군 주전급을 뜻한다.

| 지표 | 2026 | 2030 | 2035 | 2040 | 읽는 법 |
|---|---|---|---|---|---|
| 상위 270명 기여 합 (a / b) | 4,998 / 4,998 | 4,769 / 4,772 | 5,026 / 4,811 | **4,216 / 3,673** | 10년은 버티다가 2036년부터 떨어진다 (-16% / -27%) |
| 상위 270명 평균 나이 | 29.5 | 27.6 / 27.3 | 28.4 | 28.5 / 28.4 | 주전급 나이는 크게 무너지지 않는다 |
| 25세 이하 평균 잠재력 | 15.8 | 6.4 / 6.7 | 5.7 / 4.3 | 5.7 / 6.5 | 시작 때 실존 유망주가 이후 신인보다 훨씬 높다 |
| 입대 (한 구단 최대) | 69(12) / 72(11) | 52(7) / 71(9) | 53(8) / 50(9) | 43(6) / 48(7) | **첫 해만이 아니라 해마다** 한 구단 6~13명 |
| 포수가 가장 적은 구단 | 3 | 3 | 2 | 2 / 3 | diag-a는 2031년부터 **1명**인 해가 잦다 |

| 방출된 선수 중 기여 5+ | 9 / 8 | 13 / 12 | 6 / 8 | 8 / 10 | 지금 쓸 만한 선수도 잘려서 리그를 떠난다 |
| 은퇴 | 30 / 28 | 14 / 12 | 10 / 5 | 22 / 17 | |

들어오는 재능은 문제가 아니다. 한 해 신인의 재능을 견줘 보면 이렇다:

| | 전성기 10런 이상 | 20런 이상 | 30런 이상 |
|---|---|---|---|
| 실제 입단 동기 (2006~2016년 국내 입단, 실제 커리어의 전성기, 해마다 평균) | 18.3명 | 9.1명 | 4.2명 |
| 게임이 만드는 신인 (`makeDraftee` 공식, 잠재력) | 19.5명 | 8.0명 | 3.6명 |

문제는 들어온 재능이 실제 선수로 자라지 못한다는 것이다.
2041년 개막 때 2028년 이후 입단한 26~31세 선수를 보면, 살아남은 인원은 239명 / 221명이다.
이들의 평균 잠재력은 9.4 / 7.7인데 지금 기여는 6.0 / 4.7에 그친다.
지금 10런 이상인 선수는 72명 / 50명이다. 입단 연도 7개를 합친 수이므로 **한 해 7~10명**이고, 실제 입단 동기(18명)의 절반이다.

1·2차 조사에서 본 "평균 나이 26.2 → 24.4"는 전체 선수(2군 포함) 기준이다. 해마다 신인 110명이 2군을 채우기 때문이고, 주전급 나이는 27~29세로 유지된다. 나이 자체보다 **기량이 실현되지 않는 것**이 핵심이다.

## 2. 원인

1. **유망주를 다 크기 전에 방출한다 (가장 크다).**
   - 정원은 68명인데 해마다 11명을 지명하고, 육성선수(정원 외)가 없다. 그래서 해마다 57~108명이 방출된다.
   - 방출 기준(`enterRelease`·`autoReleaseUser`)은 `playerValue(…, horizonWeights('rebuild', 1))`다. 앞으로 4시즌만 보고, 시즌마다 -5런 바닥을 둔다.
   - 그래서 전성기가 7~9년 뒤인 18~20세 유망주를 서른 살 백업과 비슷한 값으로 본다. AI가 보는 잠재력에는 난이도 오차도 끼어 있다.
2. **2군 선수가 덜 자란다.**
   - 성장 판정의 출전 기회는 1군 타석 ÷ 550이다 (`offseason.ts` 결산). 2군 선수는 0이라서 성장이 0.6배로 줄어든다.
   - 실제 2군 유망주는 퓨처스리그에서 거의 매일 뛴다. 복무 중인 선수는 이미 0.4로 보정하는데, 2군 선수가 오히려 그보다 낮다.
3. **쓸 만한 방출 선수가 사라진다.** 방출되면 무소속이 되고, 개막 때(`closeOffseason`) 리그에서 지워진다. 실제로는 방출 선수를 다른 구단이 데려간다.
4. **입대가 구단과 시기를 가리지 않는다 (H1).**
   - 확률식은 `0.06 + 0.15(기여 3 미만) + 0.05 × (나이 - 23)`이고, 28세가 되면 반드시 입대한다. 구단별 상한이 없다.
   - 시작 때 29세 미만 실존 선수는 1군 기록에 1~2년 공백이 없으면 미필로 본다. 그런데 2군·상무 기록은 자료에 없어서, 실제로 병역을 마친 선수도 미필이 된다. 그 결과 첫 오프시즌에 69~72명이 한꺼번에 입대한다.
5. **포지션을 보지 않는다 (H7).**
   - 방출·드래프트·FA 판단이 모두 가치만 본다. 가상 신인 야수 중 포수 비중은 12/90(13%)이라, 한 해 리그 전체에 포수가 7명 안팎만 들어온다.
   - 포수가 많이 방출된 구단은 회복하지 못한다.

## 4. 목표 (제안, 합의 필요)

| 지표 | 지금 | 목표 |
|---|---|---|
| 상위 270명 기여 합, 15~20시즌 | -16% ~ -27% | 시작값의 ±8% 안 |
| 게임이 만든 신인 중 26~31세 기여 10+ | 한 해 7~10명 | 한 해 15명 이상 (실제 18명) |
| 방출되는 잠재력 10+ 선수 | 해마다 8~21명 | 5명 이하 |
| 입대 | 한 구단 최대 6~13명 | 상한 이하, 리그 전체 40~60명 |
| 포수 | 1명인 구단 발생 | 모든 구단·시즌 2명 이상 (복무 제외) |
| 리그 평균 (득점·타율 등) | 기준 안 | 그대로 (`npm run validate`, `docs/engine.md` 4장) |

팀 간 격차(승률 표준편차 0.055, 실제 0.073)는 엔진 쪽 문제(M2)라서 여기서는 기록만 한다.

## 5. 진행 순서

각 단계마다 `npm test`와 `npm run validate -- --years 2025,2019,2012 --seasons 100`을 돌린다. 그리고 `npx tsx tools/flow_longterm.ts --seasons 15 --seeds diag-a,diag-b`의 전후 결과를 `reports/`에 남긴다.

1. **F 포수 최소 인원**: 작고 다른 것과 엮이지 않는다. 장기 검사의 포수 경고를 자동 테스트로 만든다 (5시즌 짧은 판).
2. **E1~E3 입대**: 상한 값을 정한 뒤 한다.
3. **A 방출 기준**: 효과가 가장 클 것으로 본다. 전후 비교.
4. **C 2군 성장**: A 다음에 따로 넣어 효과를 나눠 잰다.
5. 목표에 모자라면 **D 방출 선수 시장** 또는 **B 육성선수**. 둘 다 새 조작과 화면이 필요하다.
6. **E4 입대 관리 화면**: 기능 추가이므로 마지막.

주의할 점:
- 오프시즌 판단이 바뀌면 같은 시드의 결과가 달라진다. 결과를 못 박은 테스트(M7 완료 기준 시드 등)는 다시 맞춰야 할 수 있다. 저장 형식은 B 말고는 그대로다.
- AI 판단을 바꾸면 `tests/trade.test.ts`(`docs/trade-exploits.md`)도 돌린다.

## 6. 사용자가 정할 것

1. **구단당 한 해 입대 상한** (제안 4명)과 미룰 수 있는 나이 (제안 30세).
2. **시작 때 병역 가정**: 나이별 비율을 넣을지, 상한만 둘지.
3. **방출 기준**: 유망주 보호 연차 (제안 입단 2년).
4. **육성선수**(B)와 **방출 선수 시장**(D)을 할지. A·C로 목표에 닿으면 미뤄도 된다.
5. **4장 목표 수치**를 이대로 둘지.

### 4번(육성선수)을 넣지 않은 이유

정원을 68명에서 80명으로 늘려 돌려 봤다 (육성선수 자리가 생긴 것과 같은 효과). 2040년 상위 270명 기여 합은 4,299 / 4,127로, 68명일 때(4,400 / 3,940)와 거의 같았다.
**방출(정원 압박)은 기량 하락의 주원인이 아니었다.** 진짜 원인은 가상 신인의 잠재력 수준이었다.
배율을 9 / 10 / 12로 바꿔 보니 2040년이 각각 약 4,500~5,000 / 5,200~5,800 / 6,700~7,100이었다 (하락 31세 기준). 하락 31세에서는 9.5가 맞았다.
그 뒤 사용자 요청으로 기량 하락 나이를 33세로 올리자 같은 9.5에서 2045년이 +4~15%로 올라갔다. 8.5는 -11~-6%여서, 둘 사이인 9로 정했다.
실제 입단 동기와 견준 1장의 표가 비슷하게 나온 것은, 실제 "전성기"가 좋은 한두 시즌이라 실력보다 높게 잡히기 때문으로 본다.
육성선수는 실제 제도라서 나중에 기능으로 넣을 수 있다. 다만 장기 균형을 위해 필요한 것은 아니다.
