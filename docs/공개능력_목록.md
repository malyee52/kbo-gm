# 공개 특수능력 확장 목록 (일반 스킬)

> **초안 — 사용자 승인 전** (2026-10-21). `docs/공개능력_기획안.md`의 부록이다. 효과 수치는 모두 임시값이고, 얻고 잃는 세부 규칙·상한·시작 배정·저장·밸런스는 기획안 3~8장을 따른다. 2026-10-22 하드힛 가공 자료를 반영했다 (8장, 기획안 11장).

사용자 요청 (2026-10-21, 클사장 전달): "일단 엄청 많이 만들어". 기획안 v1의 30종을 넓혀 분류를 늘리고, 긍정·양날·약점을 고르게, 직접형·비유형 이름을 섞었다. 이름 원칙과 화면 표시 원칙(비유형에는 한 줄 효과가 늘 붙는다, 약점은 직접형만)은 기획안 1.7과 같다. 다른 게임의 능력 이름은 옮기지 않았다.

## 1. 읽는 법

- **유형**: 직접 = 이름이 효과를 그대로 말한다. 비유 = 팬들이 쓰는 말투나 새로 지은 비유 (화면에서 한 줄 효과가 늘 붙는다).
- **극성**: + 긍정 / ± 양날·중립 / − 약점.
- **엔진 효과**: edge는 타석에서 타자에게 유리한 정도 (홈 이점 0.013, 좌우 상성 0.035와 같은 단위). 투수 스킬의 "edge −"는 타자 쪽으로 빼는 값이다. "±0.02 (타자 +, 투수 −)"는 타자·투수 모두에게 붙을 수 있는 스킬. 사건 배율(so·bb·hr·hit·d2·t3)은 그 사건에만 곱한다.
- **얻는 길**: 기록(결산 때 기록 조건) · 캠프(훈련 방향·코치) · 극적(경기 중 극적 장면) · 나이 · 시작(실존 선수 시작 배정, "이월"은 숨김 능력에서 옮김, "수비상"은 수비상 자료) · 생성(가상 선수·신인을 만들 때). 잃는 길은 기획안 3.1·3.4의 공통 규칙 (기록 미달 2시즌 연속, 나이, 짝 스킬로 바뀜).
- **구현 난이도** (셋 중 하나):
  - **바로**: 효과가 들어갈 엔진·리그 자리가 이미 있고, 얻고 잃는 판정도 지금 남는 기록(시즌 합계·가을야구 기록·부상·나이·계약·성장)으로 된다. 2026-10-22부터는 실존 선수 시작 판정을 하드힛 가공 자료(`data-src/hardhit_derived/`)로 할 수 있고 게임 안 판정에 경기 결과를 바꾸지 않는 집계 하나(득점권 타수·안타 또는 블론세이브)만 더하면 되는 5종(T01·T02·R01·R02·R03)도 여기에 넣었다 (8.1).
  - **기록**: 효과 자리는 있거나 식에 항 하나만 더하면 되지만, 얻고 잃는 판정에 상황별 기록(득점권·좌우·주자·이닝·점수차·월별·포수별·추가 진루 등)을 새로 세야 한다. 기획안 10장 2단계(상황별 집계)가 끝나면 된다.
  - **새 기능**: 효과 자체가 지금 엔진에 없는 기능을 필요로 한다 (AI 감독의 대타·대주자, 경기에 팀 연승·연패 넘기기, 주장, 상대 구단별 기록 등).
- **묶음**: 같은 축이거나 효과가 겹치는 스킬끼리 같은 묶음 이름을 붙였다. 3장에 묶음별로 정리했다.

## 6. 실존 선수와 관련된 표시

- 가상 선수 전용: 팀 분위기 흔듦 (실존 인물에게 붙이면 인물평이 된다).
- 실존 선수 시작 배정 없음 (게임 안 기록으로만): 부상 잦음, 더딘 복귀, 실책 잦음, 1군 적응기, 성장 정체(실존 신인 생성 배정 없음).
- 뺀 후보: "다년 계약 뒤 느슨함"(성실성 평가가 된다), "높은 요구액"(성격 평가), "이른 은퇴 고민"(개인 의사를 지어낸다), 팬들이 쓰는 비하성 별칭과 약물·사생활을 떠올리게 하는 말. 실존 선수 별명으로 굳은 말은 보류 중인 별명 고유스킬 몫이라 넣지 않았다.
- 팀 분위기 스킬은 효과를 지금 있는 자리(컨디션 `form`, 성장, 계약 요구액, 관중)에만 둔다. 클럽하우스 사건·관계 서술은 만들지 않는다.

## 7. 다른 게임과의 겹침

개념(승부처·좌우·도루·부상·노화·포수 수비 등)은 야구 게임 장르에 흔한 것이다. 이름은 이 게임에서 새로 짓거나 국내 야구 팬·중계에서 흔히 쓰는 말(이닝 이터, 대도, 진공청소기, 안방마님, 상수·변수, 필승조, 스토퍼, 원클럽맨, 티켓 파워)로 지었다. 국내외 야구 게임의 능력 목록 전부와 하나하나 대조하지는 못했으므로, 사용자가 특정 게임과 겹친다고 보는 이름은 바꾼다.
