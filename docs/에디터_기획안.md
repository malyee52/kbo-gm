# 에디터 모드 기획안 0.1

2026-10-29 사용자 지시: "잠재력을 볼수 있는 에디터 모드를 만들어. fm 인게임 에디터 같은 느낌이야"

이 문서는 기획이다. src는 아직 고치지 않았다. **[제안]** 표시는 사용자 답 전의 기획 직원 제안이고, 9장 물음에 답이 오면 [결정]으로 바꾼다.
FM 인게임 에디터는 "게임 안에서 숨긴 값을 보고 고치는 별도 도구"라는 개념만 참고했다. 화면 구성·그림·용어 목록은 가져오지 않는다.

## 0. 한 줄 요약

에디터 모드는 **게임 안에서 언제든 켜고 끄는 치트 도구**다. 켜면 숨긴 값(진짜 능력·천장·성장 성향 등)이 보이고, 선수·구단 값을 고칠 수 있다.
고침은 모두 조작 기록에 남아 재현되고, 한 번이라도 켠 게임에는 "에디터 사용" 표시가 영구히 남는다.

## 1. 지금 있는 것과 부딪히는 규칙

| 있는 것 | 에디터와의 관계 |
|---|---|
| 숨긴 값 규칙 (`tests/hidden-values.test.ts`): 화면은 `.potential`·`.drive`·`.timing`·`.ceil`·`scoutZ`·`aiPotential`·`currentRuns`·`teamStrength`를 읽지 않는다. 진짜 등급은 `parts.tsx` `useSeen` 한 곳에서만 | 에디터는 이 규칙을 일부러 깨는 기능이다. 예외를 **에디터 전용 파일 한 묶음**으로 가둔다 (5장) |
| 스카우트 추측 (`src/league/scout.ts`): 진짜 + z × σ. 추측 상태는 저장하지 않고 늘 다시 셈 | 진짜 값을 고치면 추측도 같이 움직인다 (z는 그대로라 "진짜 + 같은 어긋남"). 에디터 화면은 진짜 값과 추측을 나란히 보여 준다 |
| 우리 선수 지금 능력은 정확히 (`fix/own-exact`, 아직 main 아님) | 에디터가 없어도 우리 선수 지금 능력은 보인다. 에디터가 더 보여 주는 것은 천장·다른 구단 선수·숨은 성향 |
| 수비 등급 직접 고치기 (`def-edit`·`def-edit-off`, 2026-10-13 사용자 선택) | 이미 있는 작은 에디터. 에디터 모드와 무관하게 그대로 둔다 (에디터 사용 표시를 붙이지 않음) |
| 자유 모드 `FreeOp` (`src/fantasy/free.ts`) + `session.applyFreeOps` | move·create·ability(now·potential)·contract·teamCash·effect(trust·fans·cash…)·pick·rule·future. **에디터 고침의 바탕으로 다시 쓴다** (4장) |
| 숨겨진 특수능력 (`src/engine/traits.ts`, "어디에도 보여 주지 않는다", 사용자 결정) | 에디터에서도 숨길지는 사용자 물음 Q4 |
| 실존 선수 규칙 (사건·스캔들 금지) | 에디터는 숫자만 고친다. 사건 글을 만들지 않으므로 부딪히지 않는다. 부상을 넣는 고침은 만들지 않고 "부상 낫게 하기"만 (3.2) |
| 난이도 편집기 (`DifficultyEditor.tsx`, `settings`·`settings-off` 조작) | 난이도는 게임 규칙이라 에디터 사용 표시 대상이 아니다. 에디터 화면에서 바로 가는 링크만 |
| AI 판단 `aiPotential` = 진짜 천장 + 시드 고정 z × 난이도 오차 | AI는 계속 `aiPotential`을 쓴다. 천장을 고치면 AI도 "고친 값 + 같은 오차"로 본다 (4.4) |

## 2. 켜는 방식과 표시

### 2.1 켜기·끄기 [제안]

- **게임 중 언제든** 설정(저장·설정 화면)에서 켠다. 새 게임 시작 화면에도 같은 칸을 둔다 (처음부터 켠 채로 시작).
- 처음 켤 때 확인 창: "에디터를 켜면 이 게임에 '에디터 사용' 표시가 영구히 남습니다. 업적은 표시와 함께 남고, 구단주 평가는 그대로 진행됩니다." (Q2 답에 따라 문구가 바뀐다)
- **끄면 화면은 다시 숨김으로 돌아간다** (추측만 보임). 이미 고친 값은 그대로 남고, 사용 표시도 지워지지 않는다.
- 켜기·끄기 자체도 조작 기록에 남긴다 (`editor` 조작, 4.1). 재현에는 영향이 없지만 버그 보고에서 "언제 켰나"가 보인다.

### 2.2 에디터 사용 표시 [제안]

`league.editor` (선택 칸, 저장 형식 그대로):

```ts
editor?: {
  on: boolean;
  /** 처음 켠 때 (시즌 연도, 시즌 중이면 그날). 지우지 않는다 */
  firstOn: { year: number; day: number };
  /** 처음 값을 고친 때 (보기만 했으면 없음) */
  firstEdit?: { year: number; day: number };
  /** 고친 횟수 (연도별) */
  edits: Record<number, number>;
}
```

- 표시 두 단계: **보기만 한 게임**(firstOn만)과 **값을 고친 게임**(firstEdit 있음). 상태 줄·저장 목록·버그 재현 정보(`reproInfo`)에 작은 표 "에디터 (보기)" / "에디터 (고침)".
- **업적**: 에디터를 켠 뒤 얻은 업적에 "에디터" 꼬리표를 붙여 남긴다 (`achievements[].editor = true`). 지우거나 막지 않는다 (Q2).
- **구단주 평가**: 그대로 진행한다. 해고·신뢰는 에디터와 무관 (Q2).
- **리그 기록·연표·명예의 전당**: 그대로 남기되, 연표의 시즌 줄에 "에디터 사용 시즌" 표시 (firstOn 이후 시즌).
- **칭호** (`titles.ts`): 그대로 준다 (게임 속 사건이라 플레이어 업적이 아님).

## 3. 범위: 무엇을 보고 무엇을 고치나

### 3.1 보기 (에디터 켰을 때) [제안]

대상: **모든 선수** (우리·다른 구단·무소속·시장·드래프트 풀·해외·육성. Q3).

| 값 | 지금 화면 | 에디터 |
|---|---|---|
| 지금 능력 (갈래 등급, 20~80) | 우리 선수 정확(`fix/own-exact` 뒤), 남의 선수 추측 범위 | 진짜 등급 + 옆에 추측 범위 |
| 종합 천장(잠재, `potential`) | 스카우트 문구 4단계 | 진짜 등급 (런 → 등급, `gradeOfRuns`) |
| 갈래 천장 (`ceil`) | 없음 | 갈래별 진짜 천장 등급 |
| 숨은 성장 성향 `drive` (−1~1) | 없음 | 낱말 5단계 + 숫자 (예: "빠름 +0.62") |
| 성장 시기 `timing` (해) | 없음 | "또래보다 1.3년 늦게 큼" 같은 문장 + 숫자 |
| 조기 노쇠 `decline`, 다음 시즌 슬럼프 `slump` | 없음 | 숫자 |
| 혹사지수 `overuse` | 없음 | 숫자 |
| 선수 컨디션 | 낱말·사유 | 낱말 + 효과 값 |
| AI 구단이 보는 잠재 (`aiPotential`) | 없음 | "AI가 보는 천장" 등급 (난이도 오차가 얼마나 끼었는지 공부용) |
| 지금 기여 런 (`currentRuns`·`nextRuns`) | 없음 | 숫자 |
| 구단 진짜 전력 (`teamStrength`) | 전력 문장(`strengthTier`) | 숫자 + 순위 |
| 숨겨진 특수능력 | 없음 | **Q4** (추천: 계속 숨김) |

포지션은 영문 약자(C 1B 2B 3B SS LF CF RF DH), 등급은 20~80.

## 4. 조작 기록·저장·결정성·AI

### 4.1 조작 기록 [제안]

```ts
| { year: number; day: number; type: 'editor'; on: boolean }
| { year: number; type: 'editor-off'; on: boolean }
| { year: number; day: number; type: 'edit'; ops: EditOp[] }
| { year: number; type: 'edit-off'; ops: EditOp[] }
```

- `EditOp` = `FreeOp`에서 이름 대신 id를 쓰는 꼴 그대로 + 새 조작 (`branch`·`grow`(drive·timing)·`birth`·`heal`·`military`). 자유 모드 이야기 기록(`FantasyEntry.ops`)과 같은 적용 함수를 쓴다.
  `applyFreeOps`에서 "판타지:"·"자유 모드:" 문구를 받는 `note`를 "에디터"로 넘기면 된다. 공용 부분을 `applyOps(ops, source)`로 빼는 것은 개발 카드에서.
- 시즌 중 고침은 그날 경기 전 (`dispatchSeason`), 오프시즌 고침은 순서대로 (`dispatchOff`). 수비 고치기와 같은 꼴.
- 판타지 효과의 상한(`effects.ts` 출처별 상한)은 에디터에 걸지 않는다. 다만 값의 범위(등급 20~80, 신뢰 0~100, d −1~1)는 지킨다.
- 같은 선수 여러 칸을 한 번에 저장하면 조작 하나에 ops 여럿. 표에서 일괄 고침도 조작 하나.

### 4.2 재현·결정성

- 고친 값은 조작 기록으로 같은 날·같은 순서에 다시 적용되므로 "같은 시드 + 같은 조작 = 같은 결과"가 그대로 성립한다.
- 고침은 `Rng`를 쓰지 않는다 (값을 그대로 넣음). 갈래 천장 다시 맞추기·`skillForRuns`도 결정적.
- 보기만 하는 것은 상태를 바꾸지 않는다. `tests/game.test.ts`의 "화면 조회(`refresh`)를 끼워도 같은 결과"에 에디터 보기 값 조회를 넣어 시험한다.
- 켜기·끄기 조작은 상태 중 `league.editor`만 바꾼다 → 엔진 결과는 켜기 전후가 같아야 한다 (시험).

### 4.3 저장 형식

- `league.editor`, 업적 `editor` 꼬리표는 **선택 칸**이라 세션 저장 `format`(2)·시즌 저장 형식(3)을 올리지 않는다 (작업 방식 '저장 호환'의 선택 칸 관례).
- 새 조작 종류가 생기므로 예전 판 게임이 새 저장을 불러오면 모르는 조작이 된다. 지금도 새 조작마다 같은 사정이라 형식은 그대로 둔다 [제안].
- 월드 지문(`rosterFingerprint`)은 데이터 자료로 정해져 고침과 무관하다.

### 4.4 AI 판단

- AI 구단은 계속 `aiPotential`(진짜 천장 + 시드 고정 오차)과 자기 스카우트 추측을 쓴다. 에디터로 천장을 고치면 AI도 고친 값을 바탕으로 본다 (오차는 그대로).
  → 다른 구단 유망주 천장을 올리면 그 구단도 그 선수를 아낀다. 이것이 "현실"이라 막지 않는다 [제안].
- 숨긴 값을 플레이어가 보게 되어도 AI 판단 식은 바꾸지 않는다.
- 에디터로 바꾼 소속은 트레이드가 아니므로 AI의 트레이드 기억·호감(`fantasy negotiate`)에 남지 않는다.

## 5. 숨긴 값 시험과 코드 경계 [제안]

에디터는 "화면이 숨긴 값을 읽지 않는다" 시험의 의도적 예외다. 예외가 번지지 않게:

1. 진짜 값 읽기는 `src/game/editor.ts`의 `editorView(session, id)` 한 곳에서. `league.editor?.on`이 아니면 `null`을 돌려준다.
2. 화면은 `src/ui/editor/` 폴더만 `editorView`를 부른다. `hidden-values.test.ts`의 `UI_EXEMPT`에 이 폴더를 더하고, 대신 새 시험:
   - `src/ui/editor/` 밖 화면 파일은 `editorView`를 부르지 않는다.
   - `editorView`는 에디터가 꺼져 있으면 null (끄면 다시 숨김).
   - 에디터 폴더에서 `engine/traits`를 가져오지 않는다 (Q4가 "숨김"이면. `traits.test.ts` 그대로 통과).
3. 선수 상세(`PlayerDetail.tsx`)에는 에디터 폴더의 부품(`<EditorTab id=… />`)을 꽂기만 한다. 상세 파일 자체는 계속 숨긴 값을 읽지 않는다.
4. LLM 글(판타지·자유 모드)에 넘기는 선수 글은 에디터를 켜도 추측을 쓴다 (지금 시험 그대로).

## 6. 화면 구성 초안 [제안]

### 6.1 자리

- 메뉴 (`src/ui/menu.ts`): 새 묶음을 만들지 않고 **'아카이브' 아래 마지막 칸 "에디터"**. 에디터를 끈 때는 `blockOf` 사유 "설정에서 에디터를 켜면 열립니다" (숨기지 않는다는 규칙).
- 선수 상세 안에 **"에디터" 탭** (켰을 때만 탭이 생김. 꺼져 있으면 탭 자리에 안내 없음 — 선수 상세는 늘 열 수 있는 화면이라 막을 사유가 없다).

### 6.2 에디터 화면 (표)

```
[에디터]  ⓘ 에디터 사용 중 (고침 12회)         [끄기]
┌ 찾기: [이름·구단·포지션______] [구단 ▾] [투수/야수 ▾] [나이 __~__] ┐
│ 열: 이름  구단  POS  나이  지금  천장  격차  성향  시기  AI가 보는 천장  연봉  │
│     (지금·천장은 진짜 등급, 옆 회색 글씨가 우리 스카우트 추측)                  │
└────────────────────────────────────────────────────────────────┘
  체크한 선수 [n]명:  천장 [+5 ▾] [적용]   지금 능력 [=60] [적용]   부상 낫게 [적용]
```

- 공통 표 `DataTable`(`table.ts`)을 쓴다. 정렬·찾기는 표 부품 그대로.
- 탭: **선수** (위 표) · **구단** (자금·신뢰·팬·진짜 전력 숫자, 고치기) · **고친 기록** (조작 기록 중 edit만, 날짜·대상·전 → 후).
- 바뀌는 수치는 늘 "전 → 후"로 보여 준다 (예: 천장 55 → 65). 적용 전 미리보기 칸도 "전 → 후".
- 색은 토큰만. 고친 칸은 강조 토큰(기존 경고·강조 토큰 중 하나)으로 테두리, 진짜 값은 본문 색, 추측은 `muted`.

### 6.3 선수 상세 "에디터" 탭

- 위: 진짜 값 표 (지금·천장 갈래별, 성향·시기·노쇠·슬럼프·혹사·컨디션, AI가 보는 천장).
- 아래: 고치기 칸 묶음 (능력·천장 / 성장 / 나이·병역 / 계약·소속 / 부상). 칸마다 "전 → 후"가 바로 보이고 [저장] 한 번 = 조작 하나.
- 성장 곡선 미리보기: 지금 값과 d·τ로 앞으로 5년 예상 등급 (평균 경로, 난수 없이) — 2단계 이후 [제안].

## 7. 개발 단계 [제안]

| 단계 | 범위 | 시험 |
|---|---|---|
| E1 보기 | `league.editor`·켜기/끄기 조작·확인 창·사용 표시(상태 줄·저장 목록·`reproInfo`), `editorView`, 에디터 화면 선수 표(진짜 지금·천장·성향·시기·AI가 보는 천장), 선수 상세 에디터 탭(보기만), 숨긴 값 시험 경계 | hidden-values 새 경계, 켜기 전후 결과 같음, 끄면 null, 저장·불러오기에 표시 유지 |
| E2 고치기 (선수 하나) | `edit`·`edit-off` 조작, 능력(종합)·천장·나이·계약·소속·부상 낫게·병역, 고친 기록 탭, 업적 꼬리표 | 저장 뒤 이어 돌린 결과 = 끊김 없이 돌린 결과 (고침 포함), 재현(replay) 같음, 오프시즌 고침이 `dispatchOff`를 거침 |
| E3 고치기 확장 | 갈래별 능력·갈래 천장·성향·시기, 구단 탭(자금·신뢰·팬·지명권), 표 일괄 고침, 연표 표시 | 일괄 고침 = 조작 하나, 갈래 고침 뒤 천장 규칙 |
| E4 큰 손 | 선수 만들기(오프시즌), 리그 규정, 성장 곡선 미리보기 | 자유 모드 시험 재사용 |

각 단계는 카드 하나씩. E1이 끝나면 사용자 브라우저 확인 뒤 E2.

## 8. 하지 않는 것 [제안]

- 경기 결과·기록 고치기 (지나간 경기·통산 기록은 손대지 않는다).
- 부상·사건 넣기 (실존 선수 규칙).
- 데이터 파일(`public/data/`) 고치기. 에디터는 그 게임 저장 안에서만.
- 에디터 값 내보내기·다른 게임에 붙이기 (나중 후보).

## 9. 사용자 물음

답이 오면 위 [제안]을 [결정]으로 바꾼다. 한 번에 하나씩 묻는다 (Q1부터).

**Q1. 언제 켤 수 있나**
배경: FM 에디터는 게임 중 언제든 켠다. 켠 순간 숨긴 값이 보이므로, 새 게임 때만 고르게 하면 "중간에 잠깐 엿보기"를 막을 수 있지만 쓰기 불편하다.
① 게임 중 언제든 켜고 끔 (켠 기록은 남음) — **추천**
② 새 게임 시작 때만 고르고, 그 게임 내내 고정
③ 언제든 켜지만 한 번 켜면 그 게임에서는 끌 수 없음

**Q2. 에디터를 쓴 게임의 업적·구단주 평가·기록**
배경: 에디터로 천장을 올리면 우승·업적이 쉬워진다. 막을지, 표시만 할지.
① 모두 그대로 진행, 에디터 뒤 얻은 업적에 "에디터" 꼬리표, 연표에 에디터 시즌 표시 — **추천**
② 에디터를 켠 뒤로 업적을 얻지 않음 (구단주 평가는 그대로)
③ 구분 없이 그대로 (표시도 없음)

**Q3. 볼 수 있는 대상**
배경: FM 에디터는 모든 선수를 본다. 우리 선수만이면 남의 유망주를 엿보는 치트는 막히지만 "잠재력 보기"의 재미가 줄어든다.
① 모든 선수 (다른 구단·드래프트 풀·시장·해외 포함) — **추천**
② 우리 구단 선수만
③ 우리 선수 + 드래프트 풀

**Q4. 숨겨진 특수능력**
배경: 지금 규칙은 "어디에도 보여 주지 않는다"(2026-10-08 사용자 결정). 효과가 작은 레전드·프랜차이즈 보정이라, 보여 주면 "숨은 비밀"의 재미가 사라지고 실존 선수 평가처럼 읽힐 수 있다.
① 에디터에서도 계속 숨김 (규칙 그대로) — **추천**
② 에디터에서만 보기 (고치기는 없음), 규칙을 "에디터 밖에서는 보여 주지 않는다"로 바꿈
③ 에디터에서 보기·주기·빼기 모두 (실존 선수에게는 긍정·중립만)

**Q5. 에디터가 게임 규칙을 넘어서나**
배경: 소속 고치기로 외국인을 다른 구단에 옮기거나(트레이드 금지 규칙), 정원·외국인 한도를 넘길 수 있다.
① 넘어선다. 한도 초과는 경고만 하고 허용 (다음 개막·결산 때 기존 규칙대로 정리) — **추천**
② 규칙 안에서만 (외국인 이동 금지, 한도 넘으면 저장 막음)

**Q6. 첫 범위**
배경: 지시는 "잠재력을 볼 수 있는"이 중심이다. 보기만 먼저 내고 고치기를 다음 카드로 미룰 수 있다.
① E1 보기 먼저 → 확인 뒤 E2 고치기 — **추천**
② E1+E2를 한 번에 (보기와 선수 하나 고치기까지)
③ 보기만 만들고 고치기는 하지 않음
