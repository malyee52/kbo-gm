# 기능 전수조사 (2026-10-09)

사용자 요청: 추가해야 하거나 어색한 기능이 있는지 게임 전체를 한 번 훑는다.
방법: 로컬 서버에서 2026 LG 새 게임으로 시작 화면 → 홈 → 선수단(세 탭, 엔트리 이동) → 일정·박스스코어 → 순위 → 기록 → 트레이드(요구안·제안) → 구단 → 저장 → 시즌 끝까지 → 가을야구 → 시즌 결과 → 결산 → 오프시즌 전 단계를 직접 조작(FA 제시, 보상 추천, 외국인 재계약·계약, 드래프트 지명, 연봉 입력, 자동 방출) → 2027 개막 → 시상식·선수 성장까지 밟았다. 앞서 1999 쌍방울 플레이와 20시즌 장기 시뮬레이션에서 본 것(`docs/milestones.md` "기능 점검")은 여기서 반복하지 않는다.

심각도: **높음** = 게임 진행이나 전략을 왜곡한다. **중간** = 틀리거나 헷갈리는 표시. **낮음** = 다듬기. **제안** = 없는 기능.

## 1. 높음

| # | 화면 | 내용 | 제안 |
|---|---|---|---|
| H1 | 결산 | 첫 오프시즌에 LG에서 10명이 한꺼번에 입대했다 (주정환·이민호·조건희·이종준·성동현·고우석·박시원·강민균·이재원·송찬의). 우승 직후 다음 시즌 전력 예상이 7위로 떨어진 주된 이유. M6에서 "한 구단 8명까지"로 알고 있던 문제가 더 크다 | 구단당 한 해 입대 상한(2~3명, 임시값)과 시작 때 미필 판정 완화. 입대 시기를 플레이어가 고르는 기능(기획서 6.4)도 같이 |
| H2 | 정원 정리 | 목록이 "현재 기여가 낮은 순"이라 방금 지명한 신인(현재 30, 잠재 50~57)과 19~22세 유망주가 맨 위에 와서 자동 방출이 신인부터 자르는 것처럼 보인다. 코드를 보니 자동 방출 기준은 이미 가치(현재+잠재·나이)이고 안내 문구만 "기여가 낮은 순"이다. 매년 11명을 뽑고 68명을 지켜야 하는 압박 자체는 그대로 | 목록 정렬과 문구를 자동 방출 기준(가치)과 같게. 이번 지명 신인에 "신인" 표시. 근본 해결은 육성선수(`docs/expansion.md` A4). **(정렬·문구는 이번에 고침)** |
| H3 | 외국인 단계 | 다른 구단이 재계약하지 않은 실존 아시아쿼터 선수(토다·시라카와·왕옌청 등)의 요구액이 55만 달러로 신규 상한 20만 달러를 넘어 아무 구단도 계약할 수 없다. 후보 명단에 늘 남는다 | 풀에 넣을 때 요구액을 신규 기준으로 다시 매긴다. **(이번에 고침)** |
| H4 | 정원 정리 | "소속 선수 71/68명 · 3명을 더 방출해야"라고 나오는데 "정원까지 자동 방출"을 눌러도 표가 그대로이고 다음 단계로는 넘어간다. 원인: 화면은 복무 중 선수 6명을 세고(71), 내부 정원(`orgSize`)은 빼고 센다(65 ≤ 68). 즉 방출할 필요가 없었는데 화면이 있다고 했다 | 화면도 복무 중 선수를 빼고 세고 목록에서 따로 표시. **(이번에 고침, M8과 같은 수정)** |
| H5 | 장기 진행 | 20시즌에서 주전 기여 합 -25%, 평균 나이 30.6 → 27세 (앞선 점검에서 확인) | 신인 잠재력·성장·은퇴 모델을 함께 보정. 자동 QA 리포트(`expansion.md` E5)로 전후 비교 |

## 3. 낮음 (문구·간격)

- 가을야구 대진 설명 마침표 뒤 띄어쓰기 없음 ("…7전 4선승).시리즈 길이…"). 외국인 단계 "20만 달러까지,아시아쿼터를" 쉼표 뒤 띄어쓰기.
- 시즌 결과 화면의 "결산하면 먼저 포스트시즌을 치르고"는 가을야구를 이미 끝냈을 때도 그대로 나온다.
- 선수단 1군 표에서 "외" 배지가 이름에 붙어 텍스트로는 "오스틴외"로 읽힌다 (화면은 괜찮음, 복사·접근성용 공백).
- 홈의 "득점 / 실점 0/ 0" — 작은 글자 간격.
- 트레이드 상대 구단 카드의 "전력 7위"는 20경기 전 전력 순위인데 설명이 없다.

## 4. 빠진 기능 (제안)

우선순위는 플레이 흐름에서 자주 부딪힌 순서다.

1. **오늘의 라인업·로테이션 미리보기**: 선수단 화면에 AI 감독이 낼 타순 9명, 선발 순서, 불펜 역할. 지금은 "역할" 열로만 짐작한다.
2. **입대 관리**: 입대 예정 선수 목록과 시기 선택 (H1과 함께).
3. **육성선수·정원 완화**: 매년 11명 지명에 68명 정원은 너무 빡빡하다 (H2).
4. **시작 화면 구단 미리보기**: 전력 예상 순위, 예산, 모기업 등급, 주요 선수 3명.
5. **선수단 검색·포지션 필터**: 64~68명 표에서 이름 찾기.
6. **트레이드 정보**: 상대 선수의 계약·연봉, 우리가 내줄 선수의 가치 힌트. AI 선제안.
7. **알림 필터**: 홈 알림을 종류(결장·엔트리·구단주)로 거르기.
8. **리그 역사·통산 기록**: 시즌별 순위·우승·수상 (`expansion.md` D3·E3).
9. **도움말**: 처음 하는 사람용 한 쪽 안내 (진행 버튼, 엔트리, 오프시즌 순서).
10. **저장 칸 이름**: "저장 1~3" 대신 사용자가 이름 붙이기.
