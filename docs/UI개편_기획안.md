# UI 대개편 기획안

> **초안 — 사용자와 함께 정하는 중** (2026-10-22, 기획 직원 1단계)
> 이 문서는 고를 수 있는 안과 근거를 내는 문서다. 확정한 것은 없다. 맨 끝 "사용자가 정할 것"에서 고른 뒤 다음 단계로 간다.

## 0. 범위와 전제

사용자 지시 (2026-10-22):

1. "초보자도 아주 보기 편하고, 야구 팬들이 알 수 있고, 세부적인 걸 좋아하는 하드코어 팬들도 좋아할 만한 UI." 협업으로 방향을 같이 정한다.
2. **위에서부터**: "대분류부터 시작해. 가장 큰 메뉴들을 처음부터 다시 짜고, 그 안에 세부적으로 들어가야 할 것들, 메인 화면엔 뭘 띄울지." → 이번 단계는 대분류 메뉴 안, 대분류별 세부 목록, 메인(홈) 화면까지. 화면별 세부 배치는 다음 단계.
3. **"풋볼 매니저 UI도 많이 참고하고 OOTP UI도 많이 참고하고."** → 두 게임의 정보 구조와 관례는 참고하고 무엇을 참고했는지 밝힌다. 화면 그림·아이콘·색 배합·고유 명칭·문구는 베끼지 않는다.
4. **"지금 UI는 그냥 버린다고 생각해. 선수 기용 방식이든 뭐든 그냥 다 바꿔도 됨."** → 지금 메뉴 이름·화면 나눔·조작 방식에 매이지 않는다. 지금 화면은 "게임에 있는 기능 목록"으로만 쓰고, 기능이 빠지지 않는지 대응표(5장)로 확인한다.

그대로 지키는 규칙: 구단 로고·엠블럼·유니폼과 선수 사진·초상 없음(팀은 글자와 팀 색), 숨은 능력(실제 한계 투구 수, 혹사지수, 숨은 능력 5가지 등)은 숫자로 어디에도 보이지 않음(짐작 문구만), 게임 화면 포지션은 영문 약자(C 1B 2B 3B SS LF CF RF DH, 투수 SP RP CP), 실존 선수에게 구체적 사건을 붙이지 않음, 색은 토큰만·라이트와 다크 모두·글꼴 Pretendard.

표기: **(제안)** = 지금 게임에 없는 새 기능. 사용자 허락 전에는 확정하지 않는다. **(제안·규칙 변경)** = 게임 규칙 자체를 바꾸는 것 (예: 플레이어가 하는 일의 범위).

## 1. 세 부류 사용자

| 부류 | 누구 | 화면에서 원하는 것 | 막히는 곳 |
|---|---|---|---|
| ① 초보 | 야구도 게임 장르도 잘 모름 | 지금 뭘 하면 되는지, 잘하고 있는지 (좋다·나쁘다 한 줄), 누르면 일어나는 일 | 약어(OPS, WAR, FIP), 메뉴가 많을 때, 결정 하나에 숫자 열 개 |
| ② 보통 팬 | KBO를 보는 팬, 단장 게임은 처음일 수 있음 | 응원 팀 순위·승차, 타율·홈런·평균자책 같은 익숙한 기록, 선수 이름과 이야기, 트레이드·FA의 재미 | 세이버 지표, 연봉·캡 같은 운영 숫자, 게임 고유 개념(잠재력, 등급) |
| ③ 하드코어 | 세부 기록과 운영을 파는 팬 | 세이버 지표, 표 정렬·열 고르기, 리그 평균 대비, 투구 수·피로·스플릿, 이력 전체, 장기 계획 | 정보가 접혀 있어 여러 번 눌러야 할 때, 표에 열이 모자랄 때, 숫자가 반올림·숨김일 때 |

## 2. 참고: Football Manager와 OOTP의 정보 구조

두 게임에 대한 사실은 **기억에 의존한 것이라 확인이 필요하다** (웹 조사는 하지 않았다. 버전마다 메뉴 이름·배치가 다르다). 이름이 아니라 "어떤 방식인지"만 참고한다.

### 2.1 참고한 방식과 이 게임에서 쓰는 법

| 참고한 것 | 두 게임의 방식 (기억에 의존, 확인 필요) | 이 게임에서는 |
|---|---|---|
| 대분류 메뉴 묶음 | FM: 화면 옆에 세로 메뉴가 늘 있고, 구단 업무(선수단·전술·훈련·스카우트·이적·재정 등)가 부서처럼 나뉜다. OOTP: 위쪽 메뉴가 "우리 팀 / 리그 / 그 밖" 처럼 범위로 나뉘고, 그 아래 탭이 많다 | 3장의 안 A는 FM식 "부서" 묶음, 안 B는 OOTP식 "범위" 묶음, 안 C는 이 게임 고유의 "시간" 묶음 |
| 소식 중심 홈 | FM: 받은편지함(메시지)이 홈의 중심이고, 답해야 하는 메시지가 있으면 진행이 멈춘다. OOTP: 홈에 리그 뉴스·팀 소식이 모인다 | 홈의 "지금 할 일" 칸 + "받은 소식" 칸. 답해야 하는 일만 진행을 막고 나머지는 읽기만 (4장) |
| 위쪽 고정 막대와 진행 버튼 | FM: 화면 위 오른쪽에 늘 같은 자리의 "계속" 버튼. OOTP: 날짜와 "시뮬레이션 진행" 메뉴(며칠·다음 경기·특정 날짜까지) | 어느 화면에서든 같은 자리의 진행 버튼 하나 + 펼치는 진행 길이. 지금 게임에도 있으므로 유지하되 자리를 고정 |
| 선수 상세의 탭 구성 | FM: 선수 창이 개요·계약·기록·개발·보고서 등 탭으로 나뉜다. OOTP: 선수 창이 능력·기록·계약·이력 등 탭 | 선수 창을 탭 4~5개로 (지금은 긴 한 장 스크롤). 첫 탭은 초보용 요약 |
| 표 열을 고르고 저장하는 보기 | 두 게임 모두 선수 목록 표의 열을 사용자가 고르고 이름 붙여 저장한다 | 표마다 "기본 / 기록 / 세이버 / 내 보기" 보기 전환 **(제안)**. 지금 선수단의 능력·클래식·세이버 3쪽을 넓힌 것 |
| 능력치 표시 | FM: 1~20 숫자를 색 띠로. OOTP: 20~80 스카우트 등급 (설정으로 바꿀 수 있음) | 이미 확정된 20~80 등급(기획서 6.2)을 그대로 쓰고, 숫자 옆에 막대와 낱말("평균 주전") |
| 경기 진행·달력 흐름 | OOTP: 달력에서 날짜를 골라 그날까지 진행, 경기 결과·박스스코어로 바로 간다. FM: 경기 날에는 경기 전 준비 → 경기 → 경기 후 요약 순 | 달력 칸에서 바로 박스스코어, 경기 날 홈은 "경기 전 / 경기 후" 모습이 다르다 |
| 툴팁·도움말 | 두 게임 모두 낱말 위에 마우스를 올리면 짧은 설명이 뜬다 | 용어 풀이 (2.3) |
| 다른 구단 화면 보기 | OOTP: 어떤 구단이든 우리 구단과 같은 화면으로 볼 수 있다 | 안 B에서 "구단 보기" **(제안)** |
| 관심 선수 목록 | FM: 관심 선수를 모아 두는 목록 | "관심 명단" **(제안)**: 트레이드·FA 대상 후보를 모아 둔다 |

베끼지 않는 것: 두 게임의 화면 그림, 아이콘, 색 배합, 고유 메뉴 이름·문구, 수치 체계 중 이 게임에 없는 것.

### 2.2 두 게임에서 초보가 막히는 점과 이 게임이 피하는 법

| 막히는 점 (기억에 의존한 일반적 평가) | 이 게임의 대응 |
|---|---|
| 메뉴가 20개를 넘어 어디에 뭐가 있는지 모른다 | 대분류는 5~7개로 묶고, 처음 보는 대분류에는 한 줄 설명. 시기에 맞지 않는 항목은 숨기지 않고 흐리게 + 이유("7월 31일 트레이드 마감") |
| 받은편지함이 넘쳐 중요한 것을 놓친다 | "지금 할 일"(답해야 함, 최대 3개)과 "받은 소식"(읽기만)을 나눈다. 소식은 종류별 묶음과 하루 요약 |
| 표 하나에 열이 30개 | 기본 보기는 열 6~8개. 세이버·세부는 보기 전환으로만 |
| 능력치·지표가 무엇을 뜻하는지 설명이 없다 | 모든 약어에 용어 풀이, 숫자 옆에 리그 평균 대비 표시 |
| 결정의 결과를 미리 알 수 없다 | 조작 버튼 옆에 "이렇게 하면" 한 줄 (예: "2군으로 내리면 10일 동안 다시 못 올림" — 제도가 생기면) |
| 무엇을 안 해도 되는지 모른다 | "AI에게 맡기기"가 있는 일은 표시하고, 맡긴 상태가 기본 (지금도 엔트리 AI 맡기기 있음) |

### 2.3 정보 층 원칙

| 층 | 누구 | 무엇 | 보이는 방법 |
|---|---|---|---|
| 1층 기본 | 모두 | 결론 한 줄 + 핵심 숫자 2~3개 + 좋다/나쁘다 표시 | 처음부터 |
| 2층 펼침 | 팬 | 익숙한 기록(타율·홈런·타점, 승·패·평균자책·이닝), 근거 목록 | "자세히" 한 번 누름, 또는 선수 창의 두 번째 탭 |
| 3층 깊이 | 하드코어 | 세이버 지표(wRC+·wOBA·FIP·BABIP 등), 스플릿, 투구 수, 리그 순위·백분위, 전체 표 | 표 보기 전환, 선수 창의 기록 탭 |

- **용어 풀이**: 화면에 처음 나오는 약어에는 점선 밑줄. 누르거나 올리면 한 줄 설명 + "좋은 값" 기준 (예: "OPS 출루율+장타율. 리그 평균 약 .750, .900 넘으면 강타자"). 같은 화면에서 두 번째부터는 밑줄 없음. 설정에서 끌 수 있다 **(제안)**. 문구는 이 게임이 새로 쓴다.
- **비교 기준**: 숫자 옆에 리그 평균 대비를 작게 붙인다. 방식은 세 가지 중 고른다 (사용자 결정 6):
  - (가) 색 점: 평균보다 좋으면 초록, 나쁘면 빨강 (지금 등급 색과 같은 계열)
  - (나) 화살표와 차이: `.312 ▲.045`
  - (다) 리그 백분위: `.312 · 상위 8%`
  - 초보 층에는 (가), 깊이 층에는 (다)를 같이 쓰는 섞기도 가능
- **숨은 능력**: 숫자·등급·막대 어디에도 없다. 짐작 문구만 ("최근 공이 무겁다는 평", 엔진 2 기획안 4.5·4.6). 투구 수 자체는 공개 기록이므로 보인다. 한계 투구 수·혹사지수는 보이지 않는다.

## 3. 대분류 메뉴 안 3개

공통 뼈대 (세 안 모두):

- **위쪽 고정 막대**: 날짜·시기 / 우리 팀 이름과 팀 색 띠 / 성적(승-패-무, 순위, 승차) / "지금 할 일" 개수 / 선수 검색 칸 **(제안)** / 진행 버튼(늘 같은 자리) / 설정 톱니. 어느 화면에서든 같은 모습.
- **선수 창**: 어디서든 선수 이름을 누르면 같은 창. 탭: 요약 · 능력 · 기록 · 계약·이력 · (투수) 등판 기록. 지금 선수 상세의 모든 내용을 탭으로 나눠 담는다.
- **휴대폰 (390px)**: 대분류는 아래 탭 막대 (5개까지 보이고 나머지는 "더"), 위쪽 막대는 한 줄로 줄여 진행 버튼만 크게.
- **설정 톱니** 안: 저장·불러오기·파일, 세부 난이도, 진행 멈춤 설정, 용어 풀이 켜기·끄기, 정보·출처, 시작 화면으로.

### 안 A — 부서형 "단장 사무실" (FM의 부서 묶음을 참고)

구단 업무를 부서처럼 나눈다. 화면 **왼쪽에 세로 메뉴**가 늘 보이고 (휴대폰은 아래 탭), 대분류 7개.

| 대분류 | 한 줄 설명 (처음 볼 때) | 세부 화면 |
|---|---|---|
| **홈** | 오늘 할 일과 소식 | 홈(4장) · 받은 소식 전체 · 기사 |
| **선수단** | 우리 선수와 기용 | 명단(1군·2군·육성) · 기용(주전·서브·투수 역할·타순) · 부상·결장 · 병역(입대 계획) · 성장·훈련(시즌 뒤 성장 결과, 스프링캠프) |
| **경기** | 일정과 경기 결과 | 일정·결과 달력 · 오늘 경기(중계·직접 지휘) · 박스스코어 · 가을야구 |
| **선수 이동** | 트레이드·FA·영입 | 트레이드(직접 제안·선수 내놓기·지명권) · 선수 시장(외국인·자유계약·웨이버) · FA · 드래프트·지명권 · 선수 찾기 · 관심 명단(제안) · 이동 기록 |
| **구단 운영** | 돈·구장·사람 | 구단주·평가 · 재정 · 연봉·샐러리캡 · 구장·팬 · 감독·코치 |
| **리그** | 순위와 리그 소식 | 순위(1군·퓨처스) · 개인 기록 · 올스타전 · 시상식 · 시즌 결과 |
| **기록실** | 역사와 기록 | 연표 · 통산 순위 · 단일 시즌 기록 · 구단 역사 · 왕조·라이벌 · 명예의 전당 · 내 이력·업적 |

판타지 모드 게임에서만 대분류 **이야기**가 하나 더 붙는다 (행동·이야기·대화·기억 노트·연대기·기자회견·구단주 면담·AI 설정).

| | 좋은 점 | 나쁜 점 |
|---|---|---|
| ① 초보 | 메뉴가 늘 보여 길을 잃지 않음. 부서 이름이 할 일과 맞음 | 대분류 7개 + 세부가 많아 처음엔 많아 보임 |
| ② 팬 | "선수 이동"에 트레이드·FA가 모여 재미있는 곳을 찾기 쉬움 | "경기"와 "리그"의 경계가 헷갈릴 수 있음 (가을야구는 어디?) |
| ③ 하드코어 | 깊은 화면까지 두 번 누름. 화면 넓이를 다 씀 | 왼쪽 메뉴가 표 넓이를 차지 (접기 단추로 해결) |

작업량: **큼**. 왼쪽 메뉴 틀을 새로 만들고, 지금 여러 화면에 흩어진 것(병역, FA, 지명권)을 새 화면으로 모아야 한다.

### 안 B — 범위형 "우리 팀 · 리그 · 시장" (OOTP의 범위 묶음을 참고)

"누구의 정보냐"로 나눈다. **위쪽 가로 메뉴** 6개, 그 아래 세부 탭.

| 대분류 | 한 줄 설명 | 세부 화면 |
|---|---|---|
| **홈** | 오늘 할 일과 소식 | 홈 · 받은 소식 · 기사 |
| **우리 팀** | 우리 구단 선수와 경기 | 명단 · 기용·타순 · 일정·결과(우리 경기) · 박스스코어 · 부상·병역 · 성장·캠프 · 팀 기록(우리 선수 기록, 팀 세부 지표) |
| **시장** | 선수를 들이고 내보내기 | 트레이드 · 선수 시장 · FA · 외국인 · 드래프트·지명권 · 선수 찾기 · 관심 명단(제안) |
| **리그** | 리그 전체 | 순위 · 개인 기록 · 리그 일정·결과 · 가을야구 · 올스타 · 시상식 · 시즌 결과 · 리그 이동 기록 · **구단 보기(제안)** |
| **구단 경영** | 돈·구장·사람·평가 | 구단주·평가 · 재정 · 연봉·캡 · 구장·팬 · 감독·코치 |
| **역사** | 지난 기록 | 연표 · 통산 · 단일 시즌 · 구단 역사 · 왕조·라이벌 · 명예의 전당 · 내 이력·업적 |

**구단 보기 (제안)**: 리그 > 구단 보기에서 다른 구단을 고르면 "우리 팀" 화면과 같은 틀(명단·기록·일정)로 그 구단을 본다. 고칠 수 있는 조작만 꺼진다. 트레이드 상대를 살필 때 쓴다.

| | 좋은 점 | 나쁜 점 |
|---|---|---|
| ① 초보 | "우리 팀"만 보면 되는 구조가 분명함 | 일정·기록이 "우리 팀"과 "리그" 두 곳에 있어 헷갈릴 수 있음 |
| ② 팬 | 응원 팀 중심. 다른 구단도 같은 모양으로 볼 수 있음 | 시장 안에 탭이 많음 (오프시즌에 특히) |
| ③ 하드코어 | 구단 보기로 리그 전체를 같은 표로 비교. 표 화면이 넓음 (가로 메뉴) | 깊은 화면까지 세 번 누르는 곳이 생김 |

작업량: **중간** (구단 보기를 넣으면 **큼**). 지금 위쪽 가로 메뉴 틀을 고쳐 쓸 수 있다.

### 안 C — 시간형 "오늘 · 이번 시즌 · 내일의 팀" (이 게임 고유)

단장이 생각하는 시간 순서로 나눈다: 지금 당장 → 올해 성적 → 몇 년 뒤 → 구단 바탕 → 지난 일. 대분류 5개. 초보는 왼쪽부터 보면 되고, 하드코어는 "내일의 팀"에서 장기 계획을 판다.

| 대분류 | 한 줄 설명 | 세부 화면 |
|---|---|---|
| **오늘** | 지금 할 일 | 홈 · 지금 할 일(이벤트·제안 답·입대 선택 등) · 오늘 경기(중계·직접 지휘) · 받은 소식 · 기사 |
| **이번 시즌** | 올해 이기기 | 명단·기용·타순 · 일정·결과·박스스코어 · 순위 · 개인 기록 · 트레이드(마감까지) · 선수 시장 · 올스타 · 가을야구 · 시즌 결과·시상식 |
| **내일의 팀** | 몇 년 뒤 준비 | 유망주·2군·육성 · 성장 결과·스프링캠프 · 계약 만료 예정·FA 준비 · 병역 계획 · 드래프트·지명권 · 선수 찾기·관심 명단(제안) |
| **구단** | 돈·구장·사람 | 구단주·평가 · 재정 · 연봉·캡 · 구장·팬 · 감독·코치 |
| **역사** | 지난 일 | 기록실 6가지 · 지난 시즌 결과·시상 · 내 이력·업적 |

오프시즌에는 **이번 시즌**이 **오프시즌**으로 바뀌고 안에 8단계(FA → 보상선수 → 2차 드래프트·특별 지명 → 외국인 → 신인 드래프트 → 연봉 협상 → 정원 정리 → 개막 준비)가 들어간다.

| | 좋은 점 | 나쁜 점 |
|---|---|---|
| ① 초보 | 대분류가 5개로 가장 적고, "오늘"만 봐도 한 시즌을 돌 수 있음 | "트레이드는 이번 시즌? 내일의 팀?"처럼 경계가 애매한 것이 있음 |
| ② 팬 | "내일의 팀"이 단장 놀이의 재미(유망주·FA 준비)를 앞에 세움 | 순위·기록이 "이번 시즌" 탭 안에 묻힘 |
| ③ 하드코어 | 장기 계획 화면이 생김 (계약 만료표·병역 계획) | 같은 선수의 기록이 "이번 시즌"과 "역사"로 갈림 (선수 창에서는 한 곳) |

작업량: **중간**. 대분류 수는 적지만 "계약 만료 예정·FA 준비" "병역 계획"처럼 지금 따로 없는 모음 화면이 생긴다 (내용은 지금 데이터로 만들 수 있다).

## 4. 시기별 메뉴 변화

원칙 (세 안 공통): **대분류는 시기와 상관없이 그대로 있고, 세부 항목만 켜지고 꺼진다.** 꺼진 항목은 숨기지 않고 흐리게 + 이유를 붙인다 (지금 게임은 숨긴다). 초보가 "트레이드는 언제 할 수 있지?"를 메뉴에서 배운다. 시기를 알리는 일은 위쪽 막대와 홈이 맡는다.

| 시기 | 위쪽 막대 | 켜지는 것 | 흐려지는 것 (이유) |
|---|---|---|---|
| 정규시즌 (개막 ~ 7월 31일) | 날짜·남은 경기·진행 버튼 | 기용, 트레이드, 선수 시장, 직접 지휘 | FA·드래프트·연봉 협상 ("오프시즌에 열림"), 가을야구 ("정규시즌 뒤") |
| 정규시즌 (8월 ~ 끝) | 같음 + "트레이드 마감 지남" | 위와 같음 | 트레이드 ("7월 31일 마감") |
| 가을야구 (우리 팀 진출) | 라운드·차전, 진행 버튼(다음 경기·우리 경기까지·시리즈 끝까지·가을야구 끝까지·직접 지휘) | 가을야구 대진, 엔트리 | 트레이드·시장 |
| 가을야구 (우리 팀 탈락·미진출) | 같음, 직접 지휘 없음 | 가을야구 대진(구경) | 위와 같음 |
| 시즌 마무리 | 마무리 흐름 막대: 가을야구 → 시즌 결산(입대 선택 포함) → 시상식 → 선수 성장 → 오프시즌 | 시즌 결과, 입대 선택, 시상식, 성장 결과 | 진행 버튼 (흐름 막대의 "다음"이 대신) |
| 오프시즌 | 단계 막대: 1 FA … 8 개막 준비, 단계 마감 버튼 | FA·보상선수·2차 드래프트·외국인·드래프트·연봉·정원 정리·캠프, 감독·코치 고용 | 기용·직접 지휘 ("개막 뒤"), 트레이드 ("오프시즌 중 트레이드 없음", 지금 규칙) |

지금 게임은 시즌 마무리 흐름(가을야구 → 결산 → 시상식 → 성장 → 오프시즌)이 서로 다른 대분류(리그·선수단·오늘)를 오가 메뉴 강조가 바뀐다. 새 구조에서는 마무리 흐름 동안 **홈이 흐름 막대를 띄우고** 각 단계 화면은 그 대분류 안에 둔다 (안 C는 모두 "이번 시즌" 안).

## 6. 메인(홈) 화면

### 6.1 홈이 맡는 일

1. **지금 무엇을 해야 하는지** (초보가 길을 잃지 않게)
2. **잘하고 있는지** (성적·구단주 평가 한눈에)
3. **무슨 일이 있었는지** (소식)
4. **더 파고들 입구** (하드코어가 한 번 눌러 표로)

### 6.2 띄울 것과 순서 (정규시즌)

| 순서 | 칸 | 1층 기본 (모두) | 2층 펼침 (팬) | 3층 깊이 (하드코어) |
|---|---|---|---|---|
| 1 | **지금 할 일** | 답해야 하는 일 최대 3개 (이벤트, 트레이드 제안 답, 입대 선택, 기자회견). 없으면 "할 일 없음 · 다음 경기로" | 각 일의 마감과 "AI에게 맡기면" 결과 한 줄 | — |

## 7. 그 밖의 제안 (다음 단계에서 화면별로)

이번 단계에서 정하지 않는다. 대분류를 고른 뒤 화면별 단계에서 다룬다.

- **기용 방식** (지금 기용표 드롭다운): 포지션별 "주전 → 1순위 서브 → 2순위" 줄을 끌어 놓는 깊이표, 투수는 선발 순번과 불펜 역할 칸. 조작 방식만 바꾸는 것이라 규칙 변경은 아니다. **(제안)**
- **선수 창 탭**: 요약(초보용 한 줄 평 + 등급 4개 + 올해 기록 3개) · 능력(등급·수비·투구) · 기록(시즌·통산·스플릿·퓨처스·가을야구, 보기 전환) · 계약·이력(계약·잠재력·FA·병역·결장·이동) · 등판 기록(투수, 투구 수 포함). **(제안, 지금 내용을 탭으로 나눔)**
- **박스스코어 보강**: 투수 투구 수(엔진에 이미 있음), 승·패·세이브·홀드, 타자 포지션, 라인스코어 실책 **(제안)**
- **답해야 하는 소식** (2.2): 이벤트 창을 홈 "지금 할 일"로 옮겨 진행 버튼이 "할 일 2개 남음"으로 바뀌게 **(제안)**
- **보기 수준 설정** (초보·기본·전문): 같은 화면에서 층 몇 개를 처음부터 펼칠지 고른다 **(제안)**. 층 원칙만으로 충분하면 두지 않는다.
- **(제안·규칙 변경)**: 지금 확정 규칙은 "경기 중 작전은 AI 감독, 플레이어는 단장 + 직접 지휘(경기 개입)". 홈·경기 메뉴에 "직접 지휘"를 더 앞에 둘지는 메뉴 배치 문제지만, 정규시즌 매 경기 작전을 기본으로 맡기는 것은 규칙 변경이라 이번 개편에 넣지 않는다.

## 9. 사용자가 정할 것

1. **대분류 안**: A 부서형 / B 범위형 / C 시간형 / 섞기 (예: B + C의 "내일의 팀")
2. **메뉴 자리** (데스크톱): 왼쪽 세로 / 위쪽 가로. 휴대폰은 아래 탭으로 고정해도 되는지
3. **홈 맨 위 칸**: "지금 할 일" / "다음 경기" / "우리 팀 성적"
4. **홈 칸 순서** (6.2의 8칸): 이대로 / 바꿀 것
5. **답해야 하는 소식** (제안): 이벤트 창을 홈 "지금 할 일"로 옮길지, 지금처럼 창으로 띄울지
6. **비교 기준 표시**: (가) 색 점 / (나) 화살표와 차이 / (다) 백분위 / 층마다 섞기
7. **꺼진 메뉴 표시**: 흐리게 + 이유 (제안) / 지금처럼 숨기기
8. **보기 수준 설정** (제안): 둔다 / 두지 않는다 (층 원칙만)
9. **새 기능 후보** (각각 허락 필요): 구단 보기, 관심 명단, 표 보기 저장, 선수 검색 칸, 매직넘버, 용어 풀이 끄기
10. **판타지 모드 자리**: 대분류 "이야기" (판타지 게임만) / 홈 안 칸
11. **시안 순서**: 짚쨩 시안(`docs/UI시안_지시서.md`)을 세 안 모두 뽑을지, 고른 안만 뽑을지

### 화면별 상위 문제

- **홈**: 칸이 4개뿐이라 넓은 화면 아래가 비어 있다. "다음 경기" 칸의 "직접 지휘"가 위쪽 진행 버튼의 "직접 지휘"와 겹친다. 할 일과 소식이 한 목록이다.
- **중계·박스스코어**: 라인스코어에 안타는 있지만 실책이 없다. 투수 줄에 투구 수·승패세이브·홀드가 없고, 타자 줄에 포지션이 없다.
- **선수단**: 기용 드롭다운("포수 (수비 61)")이 표 안에 있어 표가 무겁다. 1군·2군·야수·투수·능력·클래식·세이버가 세 줄의 탭으로 나뉘어 처음 보면 어디를 눌러야 할지 모른다.
- **선수 상세**: 긴 한 장 스크롤 (능력·수비·투구·시즌·세이버·직전 3시즌·계약·병역). 초보는 첫 줄만 보고, 하드코어는 원하는 곳까지 내려야 한다.
- **시즌 마무리**: 흐름 막대는 좋다. 다만 단계마다 대분류(리그 → 선수단 → 오늘)가 바뀐다.
- **오프시즌 FA**: 설명 글이 길어 표가 첫 화면 아래로 밀린다 (휴대폰에서 특히). 표는 가로 스크롤.
- **구단 개요**: 칸 3개 아래가 비어 있다.
- **휴대폰**: 아래 탭 막대는 있다. 표 화면은 대부분 가로 스크롤.

### 있는데 안 보이는 정보

- **투구 수**: 엔진 2가 경기마다(`line.np`)·시즌 합으로 세지만 박스스코어·선수 기록·중계 어디에도 없다. 공개해도 되는 기록이다 (한계 투구 수·혹사지수는 비공개 그대로).
- **불펜 피로·연투**: 엔진이 투수마다 피로를 쌓지만 화면에는 없다. 숫자 대신 "3연투", "어제 30구" 같은 공개 사실로 보여 줄 수 있다 (한계는 비공개).
- **경기 결정 투수**: 승·패·세이브·홀드가 박스스코어에 없다.
- **팀 세부 지표**: 팀 wRC+·FIP 같은 팀 단위 세이버가 화면에 없다 (선수 단위만).
