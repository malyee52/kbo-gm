# 장기 콘텐츠 계획 (초안, 2026-10-11)

1.0 배포 뒤 기반 작업(감사 수정, 창단 구단, 재정 상세형)이 끝났다. 이제 "여러 해를 이어 하고 싶은 게임"을 만드는 콘텐츠를 짠다.
흩어진 후보(`docs/improvements.md` 3장, `expansion.md` 초안)를 모아 **기둥(pillar)** 으로 묶고, 순서를 제안한다.

## 0. 기준

장기 콘텐츠는 아래 셋 중 하나 이상을 채워야 한다.

1. **해마다 새 결정이 생긴다** — 같은 오프시즌 7단계를 반복하는 것만으로는 10년째에 지친다.
2. **돈과 선수에 쓸 곳이 생긴다** — 재정 상세형으로 돈이 쌓이는데(큰 시장 구단 4년에 300억), 쓸 곳이 투자 4종·FA뿐이다.
3. **내가 만든 역사가 남는다** — 게임 안에서 쌓인 기록·우승·스타가 보이고 이어져야 한다.

## 3. 1단계 상세: 역사와 서사

### 3.1 먼저 필요한 것: 선수 통산 기록 보존
- 지금 은퇴 선수 기록(`RetiredRecord`)에는 이름·마지막 해·마지막 구단만 있고, 무소속 선수는 오프시즌마다 리그 명단에서 지워진다 (`closeOffseason`). 기록실을 만들려면 **은퇴·방출로 떠나는 선수의 통산 기록을 남겨야** 한다.
- 통산 = 게임 시작 전 실제 기록(시즌 자료) + 게임 안 기록(`history`). 실제 기록은 자료에서 매번 읽고 저장하지 않는다 (저장 크기).
- 저장 크기가 해마다 커지는 문제(낮음 등급)와 같이 본다: 떠난 선수는 통산 합계만 남기고 시즌별 줄은 버린다.

### 3.2 D1 기록실 (새 화면 "기록실")
- **연표:** 해마다 우승·준우승, 정규시즌 1위, MVP·신인상, 우리 구단 순위. 게임 시작 전 해는 실제 자료(자료가 있는 범위)로.
- **통산 순위:** 홈런·안타·타점·도루·승·세이브·탈삼진 등 (현역은 표시). 실제 + 게임 안 합산이라, 예를 들어 최정의 통산 홈런 기록을 게임 속 선수가 넘는 순간이 생긴다.
- **단일 시즌 기록:** 시즌 최다 홈런 등. 게임 안에서 깨지면 기사로.
- **구단 역사:** 우승·가을야구 횟수, 역대 최고·최저 성적, 구단 통산 기록 순위.

### 3.3 D2 명예의 전당과 구단 레전드
- **명예의 전당:** 은퇴 뒤 헌액 판정 (임시 기준: 통산 기여, 마일스톤 2,000안타·300홈런·150승·300세이브, MVP·골든글러브 횟수). 해마다 오프시즌에 발표.
- **구단 레전드(영구결번 대신):** 자료에 등번호가 없어 "영구결번" 대신 구단 레전드로 지정한다. 우리 구단 은퇴 선수 중 기준을 넘으면 지정 버튼. 지정하면 팬덤·관중에 작은 보너스 (재정과 연결).
- **은퇴식:** 프랜차이즈 스타가 은퇴하면 다음 시즌 홈 개막전 관중 보너스와 소식.

### 3.4 D3 기사 (새 화면 "뉴스", 알림과 분리)
- 규칙으로 만드는 짧은 기사: 마일스톤(통산 2,000안타 등), 신기록, 연승·연패, 대형 FA 이적, 은퇴, 우승, 이변(꼴찌 예상 구단의 가을야구), 신인 활약.
- 실존 선수는 기록만 쓰고 인물평·사생활은 넣지 않는다.
- 종류별 필터, 우리 구단만 보기.

### 3.5 D4 라이벌과 왕조
- **왕조:** 몇 년 연속 우승·가을야구 → 왕조 기록과 업적.
- **라이벌:** 가을야구에서 자주 만나거나 순위 싸움이 잦은 상대를 라이벌로 표시. 라이벌전은 관중 보너스.

## 4. 지명권 트레이드
- 트레이드 화면에서 선수·현금에 더해 **다음 드래프트 지명권**(라운드)을 주고받는다. 1~2년 뒤 지명권까지 (임시값).
- 지명권은 원래 구단·라운드로 기록하고, 순번은 그 해 순위로 정해진다 (지금 드래프트 슬롯 구조에 "지명권 주인"을 더한다).
- AI는 지명권 가치를 "그 라운드 신인의 기대 기여"(드래프트 잠재력 식)로 매기고, 리빌딩 구단일수록 높게 친다.
- 실제 규정 확인 필요: KBO는 2023년부터 지명권 트레이드를 허용했다 (제도연표에 출처 확인 후 시대별 적용).

## 5-1. 무작위 이벤트와 한 달 진행 (2026-10-11 구현)
- 진행 버튼에 "한 달"(30일). 정규시즌 하루마다 이벤트 확률 1%에서 시작해 없는 날마다 +0.4%p(최대 35%), 생기면 1%로 (`src/league/events.ts`).
- 선택형 이벤트 12종: 광고·굿즈 제안, 모기업 격려금·실적 악화, 팬 페스티벌·할인 이벤트·자선 행사, 구장 고장, 유망주 해외 연수·전담 코치, 언론 비판, 입장권 가격. 효과는 자금·구단주 신뢰도·며칠간 관중률·유망주 잠재력.
