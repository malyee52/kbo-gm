## 1. 현금만으로 선수 사기 (Q-A)

`npx tsx tools/trade_cash_probe.ts --part cash --team KT --seed probe` (KT 자금 34.5억, 보통).
가치는 `playerValue`에 그 구단 성향 가중치(여러 해 합)를 준 값. 주전급은 그 구단 가치(이번 시즌) 상위 14명.

| | 전 | 후 (`CASH_ONLY_MAX_RUNS` 10런) |
|---|---|---|
| 현금만으로 수락되는 국내 선수 | 482명 | 324명 |
| 가치 20런 이상 | 105명 | 0명 |
| 25세 이하·15런 이상 | 64명 | 0명 |
| 주전급 | 50명 | 2명 |
| 남는 최고 가치 선수 | 두산 안재석 88.0런 20.9억 | 롯데 정보근 27세 10.0런 0.7억 |

문턱 고르기 (전 판 수락 목록에서 문턱 아래만 남긴 수):

| 문턱 (런) | 남는 인원 | 그중 주전급 | 25세 이하 10런 이상 |
|---|---|---|---|

10런을 골랐다: 12런부터 25세 이하 유망주가 다시 현금만으로 빠진다.

열어 둔 것: **우리 최하위 선수(한승택) 1명 + 자금 전부**로 문턱 위 상위 40명을 달라고 하면 39명이 수락된다 (전후 같음, 이번 결정 범위 밖).

## 2. 지명권 되팔기 (Q-B)

`--part picks`: 다음 드래프트(2027) 1·2라운드 AI 지명권을 최저가로 사서(실제 실행) 가장 비싸게 사 주는 다른 AI에 되판다(실제 실행).
"이득 장 합"은 되판 값 > 산 값인 장만 더한 값 (악용하는 사람은 이득 나는 장만 거래한다).

| 시드 | 난이도 | 전: 이득 장 합 | 후: 이득 장 합 | 후: 산 장 / 되판 장 |
|---|---|---|---|---|
| probe | 쉬움 | +20.2억 | +20.1억 | 18 / 18 |
| probe | 보통 | **+14.4억** | **0** | 3 / 0 (재트레이드 금지) |
| probe | 어려움 | +8.2억 | 0 | 3 / 0 |
| a | 쉬움 | +20.2억 | +20.1억 | 18 / 18 |
| a | 보통 | +14.4억 | 0 | 4 / 0 |
| a | 어려움 | +8.2억 | 0 | 3 / 0 |
| b | 쉬움 | +21.3억 | +21.2억 | 18 / 18 |
| b | 보통 | +15.4억 | 0 | 3 / 0 |
| b | 어려움 | +9.3억 | 0 | 3 / 0 |

쉬움은 결정대로 그대로다 (0.1억 차이는 반올림).

### 격차만 (재트레이드 허용으로 바꿔서, `--resale 1`)

| 구단·시드 | 난이도 | 이득 장 합 | 되판 장 모두의 차익 합 |
|---|---|---|---|
| KT probe·a·b | 보통 (0.55 / 0.6) | 0 | −30.5\~−30.7억 (14장) |
| KT probe·a·b | 어려움 (0.6 / 0.6) | 0 | −29.0\~−29.1억 (8장) |
| LG probe·c | 보통 | 0 | −30.5억 (14장) |
| KT probe, **단장 평판 70** | 보통 | **+0.8억** (1R 삼성 0.2·KIA 0.5·LG 0.1) | −6.3억 |
| KT probe, 단장 평판 70 | 어려움 | 0 | −27.7억 |

평판 호의(`repGoodwill`, 평판 70이면 거래마다 +1.6런)가 사고팔 때 두 번 붙어 보통 격차만으로는 0이 안 되는 경우가 있다.
그래서 카드대로 **보통에도 넘겨받은 지명권 재트레이드 금지**를 걸었다 (어려움도 금지). 어려움 격차 0은 평판 70에서도 0이다.

## 3. 바꾼 것

- `ai/trade.ts`: `CASH_ONLY_MAX_RUNS` 10 (임시값). AI가 내주는 선수 중 가치가 문턱 이상이고 상대가 선수를 한 명도 안 내면(현금·지명권만) `reject-value`, 문구 "그 선수는 현금만으로는 내줄 수 없습니다. 선수를 같이 넣어 주세요." (숫자 없음), `detail.cashOnlyBlock`. 판정 근거(gain·need)는 그대로 셈한다.
- `league/picks.ts`: `PICK_SHARE_LEVELS` 쉬움 0.4/0.8, 보통 0.55/0.6, 어려움 0.6/0.6 (임시값). 우리 제안 평가에만. AI끼리·선수 내놓기 정렬은 `PICK_SHARE` 그대로.
- `league/difficulty.ts`: 세부 난이도 `pickShare`(0·1·2)·`pickResale`(1 허용·0 금지). 묶음: 쉬움 0·1, 보통 1·0, 어려움 2·0. 예전 사용자 설정에 칸이 없으면 그 판 난이도 기본값 (`pickShareLevelOf`·`pickResaleAllowed`, 화면은 `filledSettings`). 저장 형식은 그대로 (선택 칸).
- `session.ts checkPicks`: 재트레이드 금지면 원래 구단이 아닌 구단이 가진 지명권(우리가 받아 온 것, 상대가 받아 둔 것)을 주고받을 수 없다. 넘겨받았는지는 `pickOwners`의 `from ≠ 주인`으로 알아서 새 저장 칸이 없다. 예전 저장에서 이미 넘겨받은 지명권도 같이 막힌다.
- 같은 판정을 쓰는 곳: 선수 내놓기(`shopOffers`, 현금만이면 문턱 위 선수가 안 나오고 금지면 받은 지명권 후보를 뺌), 요구안·AI가 먼저 거는 제안은 늘 우리 선수가 들어가 현금만 규칙에 안 걸린다. AI끼리 트레이드는 바뀌지 않아 longsim은 재지 않았다.
- 화면: 트레이드 지명권 고르기에서 금지면 받은 지명권을 고를 수 없고 '다시 트레이드 불가' 표시, 선수 내놓기 안내 문구, 난이도 패널에 새 두 항목.
