# 경기 엔진 2 — 0단계 기준값

지금 엔진(엔진 1, 브랜치 `feat/engine2` 커밋 `88a70f0` 시점, `src/` 변경 없음)으로 `docs/경기엔진2_기획안.md` 6장 0단계의 검증 지표를 모두 잰 값. 엔진 2의 각 단계는 이 값과 실제값을 기준으로 비교한다. 2026-10-22 측정.

실제값: 자료집 기록(`public/data/seasons/`), 하드힛 가공값(QS·블론·세이브·홀드, `data-src/hardhit_derived/pit_classic.csv`), **투구 단위 자료**(2023~2025, `data-src/pbp_derived/`, Hugging Face `slothman3878/kbo_playbyplay` CC BY 4.0을 `tools/pbp_derive.py`로 가공). 투구 단위 리그 합계는 자료집과 0.5% 안에서 맞는다 (`data-src/pbp_derived/validation.csv`).

## 다시 재는 명령

```bash
npm run validate -- --years 2025,2019,2012 --seasons 100                       # 1장
npx tsx tools/engine2_baseline.ts --years 2025,2024,2023,2019,2012 --seasons 20   # 2장
npx tsx tools/luck_check.ts --years 2012,2019,2023,2025 --seeds b1,b2           # 3장 (운의 폭, 구원)
npx tsx tools/qs_blown_check.ts --years 2012,2019,2023,2025 --seeds b1,b2       # 3장 (QS, 블론)
```

- `tools/engine2_baseline.ts`는 0단계에서 새로 만든 도구다 (기획안 "검증 도구에 새 지표 자리"). validate와 같은 시드(`validate-{연도}-{i}`)·같은 맞춤으로 돌리고 모든 구단 박스스코어를 켜서 선발·구원 운용을 경기 단위로 잰다. 박스스코어를 켜도 결과가 같은 것을 확인했다 (2025 한 시즌의 리그 합계·팀 성적 완전히 같음). 투구 수·고의4구는 지금 엔진에 없어 "없음" 칸으로 두었다 — 엔진 2 3·4·10단계에서 채운다.
- 시뮬 시간: validate 2025 시즌당 274ms, 2019 198ms, 2012 125ms (박스스코어 없이).
