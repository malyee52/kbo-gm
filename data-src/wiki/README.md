# 위키 자료 (가공값)

`tools/wiki/` 하네스가 위키데이터·한국어 위키백과·나무위키에서 뽑은 **가공값**이다. 원문·덤프·서술 노트는 저장소에 두지 않는다 (`C:/Users/ararp/kbo-gm-raw/`).
아직 게임 데이터(`public/data/`)에 반영하지 않았다. 반영은 사용자가 차이 목록을 확인한 뒤 따로 한다.

## 파일

| 파일 | 내용 |
|---|---|
| `짝.csv` | 우리 선수 ID ↔ 위키백과 문서 제목·위키데이터 ID·나무위키 문서 제목, 짝 근거(생년·구단·연도)와 점수 |
| `인적사항.csv` | 우리 자료가 빈 인적 사항을 채울 값. 신뢰도 순(위키백과 > 위키데이터 > 나무위키)으로 하나만 고른다. 출처·문서 제목·받은 날짜 . 게임에 칸이 없는 긴 글 항목(소속팀·첫 출장·마지막 경기·지도자·출신지·응원가·연봉·계약·드래프트·프로 입단)은 저장소 밖 `C:/Users/ararp/kbo-gm-raw/정리/인적사항_긴글.csv`에 둔다 |
| `인적사항_차이.csv` | 우리 값이 있는데 위키 값이 다른 것 (생년월일·키·몸무게·투타·국적). 자동 반영 안 함, 짝 확인용 |
| `기록_채움후보.csv` | 우리 시즌 기록의 빈 칸(또는 빈 행 `(행 없음)`)을 채울 후보. 위키백과 값을 먼저, 없으면 나무위키 값 |
| `기록_차이.csv` | 우리 기록과 다른 칸 (비슷해도 모두). **자동으로 바꾸지 않는다** — 사용자 확인용 |
| `출처.csv` | 쓴 문서마다 출처, 제목, 주소, 판(위키백과 revid / 나무위키 마지막 수정 시각), 받은 날짜, 라이선스 |

신뢰도: **우리 원자료(자료집 엑셀·`public/data/`) > 위키백과(+위키데이터) > 나무위키**. 빈 칸만 아래 순위 자료로 채운다 (2026-10-23 사용자 결정).
기록 항목 이름: 투수의 '아웃(이닝×3)'은 이닝을 아웃 수로 바꾼 값이다.

## 출처 표기

> 선수 인적 사항(생년월일·키·몸무게·투타·포지션·병역 등)과 시즌 기록 일부는 위키데이터(CC0), 한국어 위키백과(CC BY-SA 4.0), 나무위키(CC BY-NC-SA 2.0 KR) 선수 문서에서 사실 값만 뽑아 가공했다. 쓴 문서 제목·주소·판·확인 날짜는 `data-src/wiki/출처.csv`에 있다.
> - 위키데이터: https://www.wikidata.org — CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/deed.ko)
> - 한국어 위키백과: https://ko.wikipedia.org — CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/deed.ko). 저작자는 각 문서의 기여자(문서 역사).
> - 나무위키: https://namu.wiki — CC BY-NC-SA 2.0 KR (https://creativecommons.org/licenses/by-nc-sa/2.0/kr/). 저작권은 각 문서 기여자에게 있다 (문서 역사 `https://namu.wiki/history/<제목>`). 나무위키 2026년 8월 크롤링본(https://archive.org/details/namuwiki-data-dump-20260829, 2026-08-29 공개, `namu-md.sqlite`)을 썼다.
>
> 이 폴더의 가공값 중 나무위키에서 온 값(출처 열이 '나무위키')은 원문과 같은 CC BY-NC-SA 2.0 KR로 쓸 수 있다 (`data-src/baseballchart/`의 드래프트 자료와 같은 대우).

참고 (조사 직원 보고, 2026-10-23):
- 위의 archive.org 항목은 나무위키 공식 덤프가 아니라 제3자 크롤링본이고, 올린 사람이 CC BY-NC-ND 4.0을 표시해 두었다. 크롤러는 기여자 글의 권리자가 아니어서 글의 라이선스는 여전히 CC BY-NC-SA 2.0 KR로 본다. 덤프 파일 자체는 다시 배포하지 않는다.
- 나무위키 이용약관의 크롤링·자동 수집 조항, 데이터베이스제작자 권리(저작권법 제93조)는 확인하지 못했다.
- 위키백과 표의 기록은 출처 각주가 없는 경우가 많다 (KBO 공식·스탯티즈를 옮긴 것으로 보이나 확인 못 함).
