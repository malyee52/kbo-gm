## 다시 만들기

원본은 Hugging Face가 제공하는 파일 내려받기로만 받는다 (네이버 API·KBO 사이트를 직접 부르지 않는다. 추출 도구도 돌리지 않는다).

```bash
mkdir -p data-src/naver_pbp
for y in 2023 2024 2025 2026; do
  curl -L -o data-src/naver_pbp/kbo_pbp_$y.parquet \
    https://huggingface.co/datasets/slothman3878/kbo_playbyplay/resolve/main/v0/kbo_pbp_$y.parquet
done
python -m pip install pyarrow pandas
python -I -X utf8 tools/pbp_derive.py
```

## 만든 표

모든 표에 `year`와 `partial`(1 = 부분 시즌, 2026년은 7월 26일까지)이 있다.

| 파일 | 내용 |
|---|---|
| `count_chain.json` | 볼카운트 사슬: 연도 → 카운트 `"볼-스트라이크"` → 다음 공 결과 확률 (`ball`, `called_strike`, `swinging_strike`, `foul`, `in_play`, `hbp`, `bunt_foul`, `bunt_miss`)과 공 수 `n`. 칸마다 합 1 |
| `count_pitch.csv` | 같은 값을 건수(`n_*`)와 확률(`p_*`)로 |
| `count_pa_outcome.csv` | 카운트별 타석 결과 건수와 타율·출루율·장타율. `basis=ending`은 그 카운트에서 마지막 공을 던진 타석, `through`는 그 카운트를 한 번이라도 지난 타석 |
| `pa_pitches.csv` | 타석당 투구 수: 평균·표준편차와 1~10구·11구 이상 비율. 묶음 `all`·`K`·`BB`·`HBP`·`in_play` |
| `starter_pitches.csv` | 선발 투구 수 평균·표준편차·백분위(10·25·50·75·90), 100구·110구 이상 비율, 평균 이닝·상대 타자, 6이닝 이상 비율, 이닝당 투구 수, 투구 수와 아웃의 상관 |
| `starter_ip_pitches.csv` | 선발 투구 수 구간별 평균 이닝, 이닝 구간별 평균 투구 수 |
| `relief.csv` | 구원 등판 수(팀 경기당), 등판당 투구 수 분포·30구 이상 비율·아웃, 구원 아웃 몫, 연투(전날 등판) 비율, 3연투 비율, 같은 날 두 번 |
| `relief_rest.csv` | 구원 등판 전 휴식일 분포 (앞 등판이 선발이어도 센다, 시즌 첫 등판 제외) |
| `ibb.csv` | 고의4구 리그 수 (투구 없는 자동 고의4구 `ibb_no_pitch` + 카운트 중간 선언 `ibb_mid_count`), 팀당 평균·최소·최대, 1,000타석당 |
| `pitch_types.csv` | 구종 비율, 평균 구속·표준편차 (km/h) |
| `pitch_types_count.csv` | 카운트별 구종 비율 |
| `home_away.csv` | 홈 승·원정 승·무승부, 홈 승률(무승부 제외), 홈·원정 경기당 득점 |
| `platoon.csv` | 타자 좌타(L)·우타(R)별 타율·출루율·장타율·삼진·볼넷·홈런 비율 (`stand` 기준. 투수 좌우는 이 자료에 없다) |
| `league_summary.csv` | 엔진 검증 지표에 맞춘 리그 요약 (`metric`, `value`) |
| `validation.csv` | 집계값 대 게임 데이터(`public/data/seasons/{연도}.json` 리그 합계) 대조. 2026은 범위가 달라 넣지 않는다 |

### 정의

- 투구 결과: 원본 `pitch_result` B → 볼, T → 루킹 스트라이크, S → 헛스윙, F → 파울, H → 인플레이, W → 번트 파울, V → 번트 헛스윙. 2스트라이크 파울은 카운트가 그대로, 2스트라이크 번트 파울은 삼진.
- 타석 결과 묶음: `K` 삼진, `BB` 볼넷(자동 고의4구 포함), `HBP` 사구, `1B`·`2B`·`3B`·`HR`, `OUT` 일반 아웃(`field_out`), `DP` 병살·삼중살, `SF` 희생플라이, `SH` 희생번트, `ROE` 실책 출루, `FC` 야수선택, `CI` 타격방해.
- 선발 = 그 경기에서 팀의 첫 공을 던진 투수. 아웃·상대 타자는 타석 마지막 공의 투수에게 (타석 중 교체 시 공식 기록 규정과 다를 수 있다, 시즌 40여 타석). 투구 수는 그 투수가 던진 공 행 수.
- 연투 = 바로 앞 등판이 전날(달력). 3연투 = 그 앞 등판이 또 전날. 휴식일 = 두 등판 날짜 차 − 1.
- 상위 9명 타석 비중·상위 5명 이닝 비중은 팀별로 잰 뒤 평균. 규정 타석 = 팀 경기 × 3.1 (시즌 중 이적 선수는 합쳐서).

## 자료 결함과 처리

| 결함 | 크기 (2025) | 처리 |
|---|---|---|
| 타석 결과(`events`)가 null — 도루 실패·견제사 등으로 타석 중 이닝이 끝남 | 144타석 (2023 170, 2024 146, 2026 90) | 타석 결과·타석당 투구 수에서 뺀다. 그 공들은 카운트 사슬에 넣고, 아웃은 투수 아웃에 넣는다 |
| 사구가 투구 결과에 따로 없고 B로 적힘 | 806구 | 타석 마지막 공이 B이고 결과가 사구면 `hbp`로 나눈다 |
| 자동 고의4구는 `pitch_number = 0`, 투구 결과·구종 null | 122타석 | 사슬·투구 수·구종에서 뺀다. 볼넷 수와 `ibb.csv`에는 넣는다 |
| 고의4구 표시가 없다. 볼 3개 전에 볼넷으로 끝난 타석 = 카운트 중간에 고의4구를 선언한 것으로 본다 (마지막 공은 구속·구종이 있는 실제 볼) | 69타석 (2023 80, 2024 59) | 그 공들은 사슬에 넣고, 타석은 카운트별 타석 결과·타석당 투구 수에서 뺀다 (감독 결정이라 사슬의 끝이 아님). `ibb.csv`에 넣는다. 고의4구가 아닌 이유(공 누락)일 수도 있다 |
| 결과와 마지막 공이 어긋나는 타석 (볼넷인데 마지막 공 T, 1스트라이크에서 삼진, 일반 아웃인데 번트 파울 W, 볼 3개에서 공 3개 볼넷 등) | 10타석 안팎 | 그대로 둔다 (번트 파울 플라이 아웃은 실제일 수 있음, 나머지는 공 누락으로 보인다) |
| 타석 중 타자 교체 (2스트라이크 뒤 대타) | 13타석 | 타자는 마지막 공의 타자로. 리그 집계에는 영향 없음 |
| 타석 중 투수 교체 | 44타석 | 공은 던진 투수에게, 아웃·상대 타자는 마지막 공의 투수에게 |
| 타자 좌우(`stand`) null | 205구 (2023 4,394, 2024 954) | 좌우 표에서만 빠진다 |
| 같은 날 두 경기(더블헤더) | 구원 등판의 0.4% | 휴식일 "같은 날"로 따로 |
| 2026년 부분 시즌 | 470경기 (7월 26일까지) | 모든 표에 `partial = 1`. 맞춤 기준으로는 2023~2025를 쓴다 |
| 원본 반이닝 재전송·중복 공 | 데이터셋이 이미 걸러 냄 | 이 도구에서 중복 `(경기, 타석, 투구 번호)` 0건 확인 |

### 게임 데이터와 대조 (validation.csv)

2023~2025 리그 타석·안타·2루타·3루타·홈런·볼넷·사구·삼진·희생·병살·득점과 타율·출루율·장타율·삼진 비율·볼넷 비율이 모두 **0.5% 안**에서 맞는다 (득점·홈런·사구·볼넷은 2025 완전히 같음). 가장 큰 차이는 2024 3루타 −1개(−0.4%), 2023 희생번트 +1개(+0.1%), 삼진 −2~−5개(약 −0.04%: 2스트라이크 뒤 대타 삼진의 귀책 차이로 보인다). 1%를 넘는 차이는 없다.

## 이 자료에 없는 것

타구 종류(땅볼·뜬공·라인드라이브), 타구 방향·속도·각도, 수비수·수비 기록, 투수 투구손(좌·우), 도루·폭투·견제 같은 공 사이 주루 사건(주자는 타석 시작·끝에만 있다), 대타·대주자 표시, 포스트시즌. 2022년 이전은 데이터셋에 없다.
