# 리그 타구 유형·방향 비율 (batted_ball_derived) — 임시값 (출처 미확인)

**이 값은 확인된 실제 기록이 아니다.** 사용자가 다른 곳에서 찾은 값을 GPT가 엑셀로 정리한 것이고 원 출처를 확인하지 못했다 (2026-10-22 사용자). 엔진 목표값으로 쓸 때도 "임시값 (출처 미확인)"으로 표시한다. 원본 엑셀(`data-src/batted_ball/`)은 커밋하지 않는다.

- 만든 도구: `python -I -X utf8 tools/batted_ball_derive.py` → `batted_ball.csv` (모든 행 `status = 임시값(출처 미확인)`)
- 범위: 2010~2026, 리그 연도별. 선수별 값은 없다.
- 엑셀 주석: 타구 유형은 "유형 판정 커버리지 70~74% (아웃 타구 위주), 표본 = 유형이 판정된 타구 수", 타구 방향은 "방향 판정 커버리지 99.9% (완료 시즌), 좌우타 보정 가능 타구 수 (양타자 제외)".

## 열

| 열 | 내용 |
|---|---|
| `gb_pct`·`fb_pct`·`ld_pct`·`pu_pct`·`gb_fb`·`type_n` | 엑셀 값 그대로: 땅볼·뜬공·라인드라이브·내야 뜬공 %, 땅볼÷뜬공, 유형 표본 |
| `pull_pct`·`center_pct`·`oppo_pct`·`dir_n` | 엑셀 값 그대로: 당겨·중앙·밀어 %, 방향 표본 |
| `gb_share_of_gb_fb` | 땅볼 ÷ (땅볼 + 뜬공). 판정된 (주로 아웃) 타구 중 땅볼 몫 |
| `pbp_in_play`·`pbp_in_play_outs`·`pbp_in_play_non_switch`·`pbp_last_date` | 같은 해 투구 단위 자료(`data-src/pbp_derived/`, 2023~2026)의 인플레이 타구 수, 그중 아웃·실책·야수선택·희생, 양타 타자(한 시즌 좌·우 타석 모두 10구 이상)를 뺀 인플레이 수, 마지막 경기 날짜 |
| `type_n_per_in_play`·`type_n_per_out`·`dir_n_per_non_switch` | 표본 ÷ 위 수 (앞뒤가 맞는지 대조) |

## 표본 대조 (투구 단위 자료와)

| 해 | 유형 표본 ÷ 인플레이 | 유형 표본 ÷ 인플레이 아웃 | 방향 표본 ÷ 양타 뺀 인플레이 |
|---|---:|---:|---:|
| 2023 | 72.0% | 106.0% | 99.6% |
| 2024 | 71.6% | 109.3% | 100.7% |
| 2025 | 71.2% | 106.0% | 98.3% |
| 2026 | (범위 다름) | | |

- 유형 표본은 인플레이 타구의 71~72%로 엑셀 주석("70~74%")과 맞는다. 인플레이 아웃 수보다 6~9% 많아 아웃 전부에 안타 일부가 더해진 표본으로 보인다 → **판정된 유형은 아웃 타구 분포에 가깝다.**
- 방향 표본은 양타를 뺀 인플레이 수와 ±2% 안에서 맞는다 → 안타·아웃을 모두 담은 표본으로 보인다 (양타 판정 방식이 달라 ±2% 차이).
- 2026 엑셀 표본(유형 28,543·방향 38,252)은 투구 단위 자료(7월 26일까지)보다 크고 완료 시즌 수준이다. 엑셀의 2026 범위는 확인하지 못했다.
- 2010~2014 유형 표본(2.1만~2.3만)은 2015년 뒤(2.8만~2.9만)보다 작다. 판정 방식이 해마다 같은지 모른다.

## 쓸 수 있는 몫과 못 쓰는 몫

| 값 | 판단 | 근거 |
|---|---|---|
| LD% (2.6~4.0%) | **못 쓴다** | 흔한 값(20%대)보다 훨씬 낮다. 아웃 위주 판정이라 라인드라이브 안타가 거의 빠진 것으로 보인다. 엔진 목표로 쓰면 안 된다 |
| PU% (0.2~0.4%) | **못 쓴다** | 뜬공의 1% 미만으로 너무 낮다. "내야 뜬공"의 판정 기준을 모른다 |
| GB%·FB% (인플레이 전체 비율로) | **못 쓴다** | 안타가 대부분 빠진 표본이라 인플레이 전체 비율이 아니다 |
| 판정된 타구의 땅볼 ÷ (땅볼 + 뜬공) ≈ 0.50~0.55 (2023~2025 0.51·0.50·0.52) | **임시값으로 쓸 수 있다** | "아웃이 된 타구 중 땅볼 몫"의 리그 목표로 (엔진 5·6단계 타구 모형의 아웃 쪽). 연도 차이(2010 0.55 → 2024 0.50)도 시대 흐름으로 쓸 수 있다 |
| 방향 당겨 : 중앙 : 밀어 ≈ 47~49 : 19~20 : 31~34 | **임시값으로 쓸 수 있다** | 표본이 인플레이 전체와 맞는다. 다만 "중앙"의 범위(중견수 쪽만인지, 투수·포수·2루 베이스 쪽을 넣는지)를 몰라 구역 나누기는 정의를 정해 맞춘다. 양타 제외라 양타 타자는 따로 정한다 |
