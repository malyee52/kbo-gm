# 하드힛 가공값 (hardhit_derived)

기록 일부: 하드힛(https://hardhit.ai), 비상업적 이용. 원본 CSV(`data-src/hardhit/`)는 사용자가 직접 받았고 커밋하지 않는다. 여기에는 가공값만 둔다.

- `bat_running.csv`·`pitch_hand.csv`·`pit_classic.csv`·`clutch_*.csv`·`park*.csv`·`position.csv`·`war.csv`: `tools/hardhit_derive.py` (설명은 그 파일 머리말)
- 아래 4개: `tools/hardhit_monthly.py` (월별 표 `data-src/hardhit/monthly/hardhit_{batter,pitcher}_period_YYYY_MM.csv` 180개, 2015~2026, 2026-10-22 받음)

| 파일 | 내용 |
|---|---|
| `league_ppa.csv` | 리그 연도별 타석당 투구 수 (투수 표 투구수 ÷ 타석, 투구 없는 자동 고의4구도 타석에 들어간다), 시즌 상대 타자 100명 이상 투수의 P/PA 백분위(10·25·50·75·90)·최소·최대 |
| `league_monthly.csv` | 연·월별 상대 타자·아웃·실점·자책·9이닝당 실점·평균자책·투구수·P/PA(투수 표), 타율·출루율(근사)·장타율·OPS(근사)·삼진·볼넷 비율(타자 표) |
| `monthly_trend.csv` | 월 묶음(3·4월, 5~8월, 9·10월)별로 그 해 시즌 값에 대한 비율을 해마다 내 2015~2025 평균 낸 값(`ratio_*`)과 단순 평균(`mean_*`) |
| `monthly_check.csv` | 월별 합계 대 게임 데이터(`public/data/seasons`) 시즌 합계, 하드힛 P/PA 대 투구 단위 자료(`data-src/pbp_derived/`) P/PA |

투수별 P/PA(선수별 값)는 `data-src/hardhit/derived_players/pitcher_ppa.csv`에만 두고 커밋하지 않는다 (쓸지는 사용자가 정한다).

## 확인한 것

- 월이 빠진 해: 2016-03, 2020-03·04, 2021-03, 2022-03, 2023-03. 투수 표의 상대 타자 합이 게임 데이터 시즌 합과 0.25% 안에서 맞아(2015~2025) 빠진 달은 경기가 없던 달(늦은 개막)로 보인다.
- **P/PA는 투구 단위 자료와 같다**: 2023 3.9093 대 3.9096, 2024 3.8980 대 3.8980, 2025 3.8902 대 3.8905 (차이 0.01% 미만). 2026은 범위가 달라(하드힛은 받은 날까지, 투구 단위는 7월 26일까지) +0.1%.
- 타자 표 볼넷이 게임 데이터보다 2.5~4% 많다 (2025 +187개, 고의4구 191개와 비슷 — 고의4구를 따로 더 센 것으로 보이나 확인 못 함). 볼넷 비율은 월 사이 비교(`monthly_trend.csv`의 비율)에만 쓴다.
- 타자 표 타석이 2022 −1.3%, 2023 −0.7% 모자란다 (원인 확인 못 함). 투수 표는 온전하다. 그래서 득점·평균자책·P/PA 추이는 투수 표, OPS 추이는 타자 표로 낸다.
- 출루율은 선수별 출루율 × 타석으로 합쳐 분모를 타석으로 근사했다 (게임 데이터보다 +0.4~0.75%).
